### A.2 전체 입력 템플릿

검색 문맥이 있는 조건은 아래 템플릿을 사용한다. `{caption_i}`는 조건에 따라 1건 또는 3건이며, `{options}`에는 원 문항의 네 선택지가 직렬화된다.

```text
다음은 검색된 영상 증거(caption)입니다:
[증거 1] {caption_1}
...

질문: {question}
선택지: {options}
위 증거에 근거하여 정답 보기의 알파벳(A, B, C, D) 하나만 출력하시오.
정답:
```

검색 문맥 없음 조건은 첫 문장과 `[증거 i]` 목록을 생략하고 `질문:`부터 입력한다. 각 입력은 모델별 채팅 템플릿의 사용자 메시지 하나로 직렬화한다.

### A.3 파서·채점·불확실성

1. 생성 문자열을 대문자로 변환한다.
2. 정규식 `[ABCD]`에 처음 일치하는 기호를 예측값으로 사용한다.
3. 기호가 없으면 `?`로 기록하여 오답 처리한다.
4. 예측 기호와 원 문항 정답 기호의 정확 일치만 정답으로 채점한다.
5. 정확도 95% 신뢰구간과 조건 간 대응 차이는 문항 단위 비모수 부트스트랩 10,000회로 계산한다.
6. 조건 간 정답 여부의 대응 변화는 McNemar 정확 검정으로 평가한다.

### B.2 전체 프롬프트

시스템 메시지:

```text
너는 CCTV 영상 증거를 분석하는 전문가다. 제시된 이미지 증거만 근거로 판단한다.
```

사용자 메시지의 텍스트 부분:

```text
다음은 하나의 사건에 대한 CCTV 증거이다. 제시된 증거만 보고, 아래 후보 중 이 증거에서 관찰되는 사건 유형 하나를 고르라.
후보:
1) 비정상적인 경로로의 침범
2) 오토바이 인도 주행
3) 전동킥보드 앞뒤 2인 탑승
4) 이륜 이동수단 탑승자 일부 또는 전체 헬멧 미착용
5) 이륜 이동수단 운전자 1인 헬멧 미착용

9) 특정 인물을 뒤따라가며 배회
10) 전동킥보드 인도 주행
```

열세·우수 시점 조건에서는 해당 카메라 표지와 이미지를 텍스트 앞에 배치한다. 양측 시점 조건은 `c1`, `c2` 순서로 각 카메라 표지와 이미지를 배치한다. 이미지 없음 조건은 이미지를 생략한다.

### B.3 파서·채점·불확실성

1. 생성문에서 첫 JSON 객체를 파싱하고, 실패하면 `event_class` 값만 정규식으로 추출한다.
2. `event_class`가 후보 전문과 일치하면 그대로 채택한다.
3. `N` 또는 `N) 텍스트` 형식은 해당 번호의 후보로 정규화한다.
4. 생성문에 후보 전문 하나만 유일하게 포함되면 그 후보로 정규화한다.
5. 복수 후보가 일치하거나 어느 후보도 일치하지 않으면 오답 처리한다.
6. 정규화한 사건 범주와 제공 정답 범주의 정확 일치만 정답으로 채점한다.
7. 우수 시점−열세 시점 차이는 사건 단위 대응 부트스트랩으로 평가한다.
8. 우수 시점−양측 시점은 5%포인트 등가 한계의 두 단측 검정으로 평가한다.

원천 결과와 실행 기록은 `../../Datasets/processed/aihub_multi_angle_cctv/20260708/results/multiview_answer_vlm_*_400/`에 보존되어 있다. Qwen2.5-VL과 Qwen2-VL 실행 매니페스트는 기존 실행 뒤 재현성 보강을 위해 사후 재구성되었으며, 파일의 `reconstructed=true`와 설명을 유지한다. InternVL3와 Idefics2 매니페스트는 실행 시 생성되었다.

## C. 대형 교차로 코퍼스 관련 클립 회수 판정

- 최초 영상 3,000개에서 중앙 프레임 규칙 적용 불가 33개를 제외해 2,967개를 구성했다.
- 객체 수 원천 주석이 없는 228개를 결과와 무관하게 제외해 평가 모집단 2,739개를 확정했다.
- 검색 후보는 객체 수 주석이 있는 133,977개 프레임이다.
- 정확 색인과 의도적 열화 색인의 상위 1개 라벨 일치율 차이는 버스 +0.8%포인트, 이륜차 −1.1%포인트였다.
- 정확 색인만 일치한 사례는 각각 288건과 307건이었다.
- 사전 진행 기준은 범주별 일치율 차이 5%포인트 이상과 정확 색인만 일치한 사례 200건 이상을 동시에 충족하는 것이다.
- 두 범주는 사례 수 기준만 충족하고 일치율 차이 기준에 미달했다. 따라서 이 분기의 VLM 답변 생성은 수행하지 않았다.
