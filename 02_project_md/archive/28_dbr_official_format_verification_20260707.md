# DBR 공식 투고 양식 확인 기록

작성일: 2026-07-07

## 확인 결론

데이터소사이어티 DBR에는 공식 `논문지 투고 규정`과 원고 작성 규정이 존재한다. 다만 2026-07-07 기준 공식 페이지에서 별도의 `.hwp`, `.doc`, `.docx` 템플릿 다운로드 링크는 확인되지 않았다.

따라서 본 연구 제출본은 특정 템플릿 파일에 맞춰 작성하는 방식이 아니라, 공식 작성 규정에 맞춘 A4 기반 MS Word/HWP 원고로 관리한다.

## 확인한 공식 출처

- 논문지 투고 규정: https://dbsociety.kr/dbr_submission_guide/
- 이전/보조 투고 규정 페이지: https://dbsociety.kr/journal-submission-rules/
- 참고문헌 스타일 가이드: https://ieeecs-media.computer.org/assets/pdf/2016CSStyleGuide.pdf

## 공식 페이지에서 확인한 사항

- 심사용 원고 작성 규정 섹션이 존재한다.
- 채택된 원고의 최종본 작성 규격 섹션이 존재한다.
- 참고문헌은 IEEE Computer Society Reference Style Guide를 따른다.
- 심사용 원고는 아래한글 또는 MS Word로 작성한다.
- 원고는 A4 기준 20쪽 이내로 작성한다.
- 심사용 원고에는 감사의 글을 포함하지 않는다.
- 첫 쪽에는 국문/영문 제목, 국문/영문 저자명, 소속과 직위, 세부분야, 교신저자 정보를 포함해야 한다.

## 현재 제출본에 대한 적용 방침

현재 원고 `kiise_dbr_manuscript_v1_true_multimodal_DBR_review.docx`는 DBR 심사용 규정을 반영한 A4 기반 MS Word 제출 후보로 유지한다. 공식 템플릿 파일이 확인되지 않았으므로, Word/HWP 육안 검수에서 다음 항목을 우선 확인한다.

1. A4 20쪽 이내 여부
2. 첫 쪽 저자 정보와 교신저자 정보 완비 여부
3. 국문/영문 초록 길이
4. 국문/영문 키워드
5. 표 제목 상단, 그림 제목 하단 배치
6. 참고문헌 번호형 및 IEEE식 표기
7. 심사용 원고의 감사의 글 제외 여부

## 남은 제출 리스크

공식 다운로드 템플릿은 확인되지 않았지만, DBR 편집위원회가 별도 내부 양식을 이메일로 제공할 가능성은 배제할 수 없다. 따라서 제출 직전 또는 편집위원장/간사에게 문의할 때는 다음과 같이 확인한다.

> DBR 투고 규정 페이지에는 별도 HWP/DOCX 템플릿이 확인되지 않아 A4 MS Word 원고를 작성했습니다. 별도 제출 양식 파일이 있는지 확인 부탁드립니다.
