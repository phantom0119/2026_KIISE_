# 5.2.1–5.2.2 실험 결과 — RQ1과 RQ2

## RQ1. 비순환 작업 부하 검증

### 실험 논리: 진단 → 정량화 → 차단

1. **진단**: 기존 VRU-Accident와 지능형 관제 CCTV 작업 부하를 세 원천 규칙으로 수리하고 동일 질의의 수정 전후 성능을 비교한다.
2. **정량화**: 깨끗한 AI Hub 교차로 작업 부하에 정답 기반 조건 또는 정답 라벨 재진술 문서를 의도적으로 주입한다.
3. **차단**: 원천·필드·문구·토큰 유출을 자동 검사한다.

### 검색 파이프라인

`클립·설명문·메타데이터 적재 → 자연어 질의+predicate 입력 → 검색 전략 실행 → top-10 반환 → qrels 대조 → nDCG@10/Recall@10`

### 기존 작업 부하 수정 전후

| 데이터·검색 방식 | 수정 전 | 수정 후 strict | 수정 후 semantic |
|---|---:|---:|---:|
| VRU 검색 전 조건 적용 | 0.9736 | 0.3174 | 0.2974 |
| VRU 벡터 단독 | 0.4476 | 0.1845 | 0.2649 |
| VRU BM25 | 0.4495 | 0.0918 | 0.1607 |
| 지능형 CCTV BM25 | 0.9600 | 0.1111 | 0.1667 |
| 지능형 CCTV 검색 전 조건 적용 | 1.0000 | 0.8395 | 0.8395 |

수정 후 점수 하락은 시스템이 나빠진 것이 아니라, 기존 점수에 섞였던 정답 재사용 효과가 제거되어 현실적인 난도가 드러난 것이다.

![그림 2. 순환성 수리 전후와 통제 주입 효과](./assets/figure_02_circularity.png)

### 통제 주입 결과

| 처리 | nDCG@10 | 비순환 기준 대비 Δ | 해석 |
|---|---:|---:|---|
| 비순환 기준선 | 0.1810 | 기준 | 실제 출발점 |
| 같은 수 무작위 통과 1,000회 평균 | 0.1200 | −0.061 | 단순 후보 축소는 이득 아님 |
| 정답 기반 조건 주입 | 1.0000 | +0.819 | 후보가 정답이므로 구조적 만점 |
| 라벨 재진술 문서 주입 | 0.8537(본문 반올림 0.8540) | +0.6727 | 문서 경로 누수만으로 큰 상승 |

정답 라벨 재진술에서는 관련 클립 캡션 끝에 조건별 고정 정답 정의 문장을 붙이고 다시 임베딩·색인한다. 총 `1,367개`의 클립–문장 연결이 주입되며, 문장이 모델 입력 길이에서 잘리지 않았는지 검사한다.

### RQ1 결론

- 알고리즘·코퍼스·질의를 고정해도 평가 데이터의 생성 경로만 오염하면 점수가 최대 `4.7배`까지 부풀 수 있다.
- 동일 선택도 무작위 대조가 낮다는 점은 상승이 단순 후보 수 감소가 아니라 정답 정보 선택 때문임을 보여준다.
- RQ2–RQ6은 세 원천 분리와 자동 감사를 통과한 후에만 해석할 수 있다.

> 주의: 제출본의 `0.181005` 기준선은 주 격자 정렬 Qwen 반복이다. canonical에 함께 남아 있는 BGE-M3 통제 주입 기준선 `0.170033`은 별도 트랙이므로 한 표에서 같은 기준선처럼 섞지 않는다.

## RQ2. 검색용 데이터 구성

### 통제 조건

- 코퍼스 3,000개, 질의 85개
- Qwen3-VL-Embedding-2B의 통합 2,048차원 공간
- 벡터 단독 검색, Flat 정확 검색
- 검색용 데이터 구성만 변경

### 품질·지연·저장량

| 검색용 데이터 | strict nDCG@10 | semantic nDCG@10 | 설명문 대비 Δ [군집 95% CI] | p50(ms) | float32 벡터(MB) |
|---|---:|---:|---|---:|---:|
| 영상 설명문 | 0.063 | 0.181 | 기준 | 1.15 | 24.6 |
| 대표 이미지 | 0.063 | 0.186 | +0.005 [−0.075,+0.079] | 1.21 | 24.6 |
| 이미지·설명문 결합 | 0.079 | 0.218 | +0.037 [−0.005,+0.074] | 1.24 | 24.6 |
| 다중 이미지 | 0.101 | 0.352 | +0.171 [+0.018,+0.316] | 3.65 | 68.4 |
| 이중 색인 | 0.089 | 0.293 | +0.112 [−0.004,+0.228] | 4.96 | 93.0 |

### 결과 해석

- 대표 이미지는 설명문과 같은 저장 예산에서 뚜렷한 차이를 보이지 않는다.
- 이미지·설명문 결합은 같은 단일 벡터 예산에서 중간 품질 후보지만 군집 CI가 0을 포함한다.
- 다중 이미지는 가장 높은 semantic 점 추정치와 양의 군집 CI를 보이지만, 저장량 `2.8배`, p50 지연 `3배 이상`을 요구한다.
- 이중 색인은 품질을 높이지만 저장량과 지연이 다섯 구성 중 가장 크다.
- 전체 storage family의 BH 보정 `q=0.112`이므로 다중 이미지를 모든 환경의 보편적 승자로 단정하지 않는다.

### 설명문 생성 모델 ablation

Qwen3.5-9B는 Qwen2.5-VL-7B-Instruct 대비 semantic nDCG@10이 AI Hub `+0.102`, MEVA `+0.168`, UCA `+0.054` 증가했다. 이는 검색용 데이터의 품질이 캡션 생성기에 의존함을 보여준다. 다만 모델·도메인 상호작용이 있으므로 “최신 모델이면 항상 우수하다”는 일반화는 금지한다.

### 112개 구성과 파레토

![그림 3. 112개 데이터베이스 구성의 품질–지연 파레토 분포](./assets/figure_03_pareto.png)

16개 데이터–계획 조합과 7개 물리 설정을 결합하면 112개 구성이 된다. 같은 다중 이미지+Flat에서도 strict 기준은 사전 필터가 벡터 단독보다 `+0.161` 높지만 semantic 기준은 `−0.093` 낮다. 따라서 표현 선택은 품질 숫자 하나가 아니라 정답 계약·지연·저장 예산을 함께 보고 결정한다.
