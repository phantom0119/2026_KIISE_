### S2 — 고결합 층 확충 + 결합도 임계 민감도 (설계 정정)

## 3. 보강 실험의 수정된 우선순위

### S2. 고결합 효과

현재 데이터에서 V 임계나 최소 양성 수를 바꾸고 유리한 쌍을 추가한 뒤 같은 데이터로 유의성을 판정하면 사후 선택 편향이다. 현 자료의 임계 스윕은 민감도 분석으로만 보고한다. 의미 정의·V 임계·최소 양성 수·제외 규칙을 먼저 동결한 뒤, 교차로 또는 시간 블록을 발굴/평가로 분리하거나 독립 데이터셋에서 한 번 검정해야 한다. 독립 평가 전에 현재의 “탐색적, 2쌍 한정”을 승격하지 않는다.

### S3. 군집성의 인과 효과

선택도를 보존한 라벨 셔플과 합성 군집 강도 용량-반응은 적절한 기전 실험이다. 다만 군집도 지표, 셔플 횟수, 강도 격자, 주 결과를 실행 전에 동결해야 한다. 현재 자료에서 개발한 결과는 사후 기전 검증으로 보고하고, 독립 시드·코퍼스에서 셔플 음성 대조와 용량-반응이 함께 재현될 때만 인과 문장을 검토한다.

### S4. ANN→답변 효과

검색 불일치 질의를 과표집하면 호출은 줄지만 모집단 평균 효과가 바뀐다. 따라서 원 질의 분포의 평균 효과와 검색 불일치 층의 조건부 효과를 분리해야 한다. 모집단 효과는 층별 모집단 크기와 표집 확률을 기록해 역확률 또는 층화 가중으로 복원한다. 표본 수는 적중 건수만이 아니라 대응 불일치율과 최소 관심 효과를 이용한 McNemar 검정력으로 정한다. 기존 이진 존재 질문은 내용-유발 yes 편향이 확인되었으므로 다지선다 또는 값 질문으로 교체하고, 질문·프롬프트·중단 규칙·주 추정량을 VLM 호출 전에 동결한다.

### S5. 동적 운영 검증

현재 부분 색인 손익분기 정책은 정적 작업 부하에서 계산한 설계안이다. 실시간 유입, 색인 생성·갱신·폐기, 조건 빈도 변화, 동시 질의를 포함한 trace replay가 없으므로 “운영 정책 확립”이라고 부르지 않는다. 게재 전 필수 실험은 아니지만 시스템 기여를 강화하려면 후속 우선순위가 높다.

- 선택도 `s={0.05,0.10,0.20,0.40}`, 집중도 `c={0,0.25,0.50,0.75,1.0}`,

## 6. S4 — ANN→답변 전파

### 6.1 문항 타당도 게이트

- 기존 이진 yes/no 질문은 내용 유발 yes 편향 때문에 주 분석에서 제외한다.
- frame annotation으로 정답을 얻을 수 있는 3지선다 값 질문만 사용한다:
  `bus_count={0,1,2+}`, `bike_count={0,1,2+}`.
- 이 실험의 범위는 **top-1 검색 증거를 VLM이 값으로 판독하는 nearest-neighbor evidence classification**이다. 자유형 다중 문서 RAG 전체로 일반화하지 않는다.
- 클래스별 60개, category별 180개의 균형 표본에서 oracle source frame, class-mismatched distractor, closed/no-image 조건을 비교한다.
- distractor는 다른 class를 가지되 가능한 경우 같은 `intersection_id×hour`, 다음으로 같은 intersection, 다음으로 같은 hour에서 고른다. 이 계층과 실패를 item별 기록한다.
- prompt, 보기 순서, parser를 고정하며 보기 순서는 item hash로 균형화한다.
- 게이트: oracle macro accuracy의 95% CI 하한이 `1/3`보다 크고,
  oracle이 distractor보다 최소 10%p 높으며, 어떤 단일 예측 class도 70%를 넘지 않는다.
- bus와 bike 중 게이트를 통과한 category만 본 실험에 진입한다. 둘 다 실패하면 S4는 `invalid_measurement`로 중단한다.

### 6.2 retrieval 처치와 추정량

- exact index와 `e1a_locked_configs.json`의 strong degradation을 고정한다.
- source frame을 query로 사용하고 self-exclusion 뒤 top-1 frame만 VLM 증거로 제시한다. gold는 source frame의 TL_3 frame annotation class다.
- 검색 코퍼스도 TL_3 frame annotation이 있는 frame으로 한정해 source·evidence class 정의를 동일하게 유지한다. 원 E1A의 seed `20260711`로 뽑은 video 표본과 중간 frame 규칙을 재구성하되, TL_3 source가 없는 항목은 결과와 무관한 `missing_source_annotation`으로 기록한다.
- category별 검색 조작 gate는 `exact class-match−strong class-match ≥5%p`이고 `exact-hit/strong-miss`가 200건 이상인 경우다. 통과하지 못한 category는 답변 전파 본 실험에 넣지 않는다.
- 모집단 전체를 먼저 검색해 `exact_hit/strong_hit` 4개 층의 크기를 기록한다.
- 불일치 층을 과표집하되 item의 포함확률을 저장한다.
- 1차 추정량: 원 질의 분포의 inverse-probability-weighted paired accuracy 차이.
- 2차 추정량: `exact_hit != strong_hit` 층의 조건부 paired accuracy 차이.
- McNemar exact test와 intersection-cluster bootstrap 95% CI를 함께 보고한다.

### 6.3 검정력과 중단

- 본 호출 전 10% 고정 pilot에서 paired discordance를 추정한다. pilot item은 본 분석에서 제외한다.
- 최소 관심 효과는 원 분포 `5%p`, 불일치 층 `10%p`, 양측 alpha `0.05`, power `0.80`이다.
- 필요한 VLM 호출 수가 가용 frame 또는 사전 상한 4,000 item-pairs를 넘으면 full run을 하지 않고 `underpowered`로 보고한다.
- 원 분포 효과가 검출되지 않고 불일치 층만 검출되면 “불일치 층에서의 조건부 전파”로만 서술한다.

## 1. 현재 결론

1. **RQ5 군집 기전은 보강 성공**: 선택도를 정확히 고정한 라벨 셔플 음성 대조와 합성 군집 농도-반응 양성 대조가 2개 코퍼스×2개 색인에서 모두 통과했다. 따라서 검증 범위를 “두 CLIP 코퍼스의 postfilter HNSW·IVF-Flat”으로 한정하면, 군집 집중이 재현율 손실을 유발한다는 기전 표현이 가능하다.
2. **RQ3 고결합 일반화는 승격 불가**: 교차로를 5-fold로 완전히 분리해도 고결합 방향은 5/5 fold에서 양수였지만, 고결합 family 수가 5개 미만이다. 현 원고의 “탐색적, 2쌍 한정”을 유지한다.
3. **ANN→답변 대규모 호출은 중단이 정답**: 편향을 줄인 3지선다 답변 실험에 앞서 top-1 task-label 조작을 확인했으나 exact−strong 차이가 bus +0.8%p, bike −1.1%p였다. 사전 5%p 조작 gate를 모두 실패했으므로 VLM을 호출하지 않았다. 현재 병목은 표본 수가 아니라 **과제 관련 검색 처치의 부재**다.
4. **E0 프롬프트-표적 결합은 중대한 민감 요인**: 동일한 3,000개 프레임·모델 snapshot·디코딩·질의·정답표·BGE-M3·정확 검색에서 프롬프트만 과제-중립형으로 바꾸자 B2 의미론적 nDCG@10이 0.1700에서 0.0855로 49.7% 하락했다. 따라서 직접 정답 재사용을 차단했다는 사실을 프롬프트 중립성으로 확대하면 안 된다.

## 2. E0 — 과제-중립 캡션 프롬프트 대조

- 같은 3,000개 중간 프레임, Qwen2.5-VL-7B snapshot, `max_pixels=200704`, `max_new_tokens=110`, greedy decoding을 고정했다.
- 질의 85개, 25개 `(predicate, relevance_def)` family, semantic qrels, 기존 질의 벡터, BGE-M3 snapshot, L2 정규화와 exact inner-product 검색을 양 조건에서 동일하게 사용했다.
- 1차 결과인 B2 의미론적 nDCG@10은 과제-인지 `0.1700`, 과제-중립 `0.0855`, 차이 `−0.0845`였다.
- family-cluster bootstrap 95% CI는 `[−0.1672, −0.0044]`, family-cluster sign-flip 양측 `p=0.0346`이었다.
- 질의별 과제-중립 승/동률/패는 `20/18/47`, 상대 하락은 `49.7%`였다.
- 빈 캡션은 양 조건 모두 0건이었다. 과제-인지/중립 캡션의 평균 Qwen token 수는 `73.9/93.9`, 110-token 이상 진단 건수는 `11/507`이었다. 길이와 잘림 가능성은 프롬프트 처치가 만든 매개이므로 주 추정량에서 사후 보정하지 않았다.
- 과제 범주별 문서 출현률은 과제-인지/중립에서 bus `0.974/0.338`, truck `0.870/0.154`, two-wheeler `0.970/0.053`, stopped-or-parked `0.992/0.618`로 감소했다.

**판정**: 본 작업 부하는 정답 주석의 직접 재사용을 차단하지만, 과제 범주를 열거한 캡션 프롬프트에 강하게 의존한다. E0은 어떤 단일 매개가 하락을 만들었는지 분해하지 않으므로 “범주 단어가 성능을 인과적으로 높였다”까지 주장하지 않는다. 허용되는 표현은 “이 결과는 과제-인지 프롬프트 조건부이며 프롬프트 비의존적이지 않다”이다.

## 3. S2 — 교차로 차단 결합도

- 63개 `intersection_id`를 결과와 무관한 안정 hash로 5-fold 배정했다.
- 각 fold에서 Cramér's V는 나머지 4-fold에서만, B4−B2 semantic nDCG@10은 held-out 교차로에서만 계산했다.
- 85질의×5-fold 425개 중 407개가 고정 support gate를 통과했다. 제외는 semantic positive 부족 12개, B4 후보 부족 6개다.
- 연속 V와 held-out Δ의 Spearman ρ는 `0.383`, 양측 `p=0.059`, family bootstrap 95% CI `[-0.088, 0.727]`이다.
- high fold 평균 Δ는 `+0.139, +0.111, +0.283, +0.218, +0.147`로 5/5 양수였다.
- 그러나 유효 high family 수가 사전 기준 5개에 못 미쳐 promotion gate는 실패했다.

**판정**: 동일 교차로 누출을 막아도 방향은 유지되지만, 지지 family 수 부족은 해소되지 않았다. “강한 결합에서 사전필터가 일반적으로 유의하게 우세하다”는 문구는 금지한다.

## 3. 아직 남은 위험

### P0 — 외부 아티팩트 접근 주소

원고와 로컬 산출물에는 재현에 필요한 스크립트·manifest·질의별 결과·해시가 있으나, 심사자가 접근할 익명 또는 공개 URL은 없다. 이는 새 실험이 아니라 저자·학회 정책 결정 사항이다.

필요 조치:

- AI Hub 등 원자료 이용약관을 확인해 재배포 가능한 범위를 확정한다.
- 원본 영상과 모델 가중치는 제외하고 스크립트, 전체 프롬프트, query/qrels ID, 집계·질의별 결과, manifest, SHA-256을 공개한다.
- 익명 심사가 필요하면 저자 식별 정보와 로컬 절대 경로를 제거한 패키지를 만든다.
- URL이 실제 접근 가능한 상태가 된 뒤에만 원고에 아티팩트 공개 문장을 추가한다.

### P0 — 개정 PDF의 지면·도표 검수

`paper_final.pdf`는 이미 투고한 원본이므로 변경하지 않았다. 현재 수정은 `0_paper_script.md`에만 있다. 재심 또는 수정 투고 전에는 별도 개정 PDF를 만들고 표 분할, 그림 가독성, 참고문헌 줄바꿈, 전체 페이지 수를 실제 양식에서 확인해야 한다.

### P1 — 프롬프트 민감성의 기전 분해

E0은 프롬프트 전체를 변경했으므로 범주 열거, 출력 길이와 110-token 잘림 가능성 중 어느 매개가 하락을 만들었는지 식별하지 않는다. 현재 원고처럼 의존성만 공시하면 추가 실험은 필수가 아니다. “범주 열거 자체의 효과”를 주장하려면 다음 신규 프로토콜을 결과 전에 동결한다.

- 요인 A: 현재 범주 열거 / 구조를 맞춘 범주-중립 문구
- 요인 B: 생성 상한 80 / 110토큰
- 두 프롬프트는 문장 구조와 입력 token 수를 가능한 한 맞추고, 같은 3,000개 프레임·snapshot·greedy·질의·qrels·BGE-M3를 사용한다.
- 1차 추정량: 두 token budget에 평균한 범주 열거의 B2 semantic nDCG@10 주효과
- 2차: 범주×budget 상호작용, 출력 길이·상한 도달률
- 검정: 25개 query family 군집 부트스트랩, 주효과 1개를 primary로 고정
- 성공 기준: 두 budget에서 방향이 같고 주효과 CI가 0을 배제할 때만 범주 열거 기전을 주장

### P1 — ANN→답변 종단 효과

현재 병목은 호출 수가 아니라 exact와 strong 색인이 과제 라벨을 거의 같은 비율로 회수한다는 점이다. 다음 실험은 held-out 결과를 보며 처치를 고르면 안 된다.

1. 교차로를 development/held-out으로 먼저 분리한다.
2. development에서만 ANN 설정·evidence 정의를 선택한다.
3. held-out에서 exact−degraded 과제 라벨 일치율 차이 ≥5%p 및 exact-hit/strong-miss ≥200을 확인한다.
4. 게이트 통과 범주만 고정 3지선다 VLM 실험으로 보낸다.
5. 모집단 IPW 효과와 불일치 층 조건부 효과를 분리 보고한다.

게이트가 다시 실패하면 “종단 효과 없음”이 아니라 “유효한 retrieval intervention 부재”로 보고한다.

### P2 — S3의 외적 타당성

S3는 통제 기전에는 충분하지만 사후 보강이며 CLIP 두 코퍼스와 postfilter HNSW·IVF-Flat에 한정된다. 더 넓은 인과 주장이 필요할 때만 다른 encoder 또는 실제 DBMS 한 종류에서 독립 반복한다. 현 원고는 범위를 이미 제한했으므로 심사 대응을 위해 즉시 필요한 실험은 아니다.

### P2 — 동적 운영 비용

현재 지연·공간 결과는 정적 단일 호스트 계측이며 원본 영상 I/O, 캡션 생성, 온라인 임베딩, 네트워크와 VLM 생성 비용을 포함하지 않는다. 현 원고는 데이터베이스 검색·색인 계층의 부분 비용으로 한정했으므로 결함은 아니지만, 운영 배포 주장으로 확대하려면 유입·갱신·동시 질의와 종단 비용을 별도 측정해야 한다.
