# 논문 개요와 Research Questions

## 논문 정보

- 한글 제목: **종단형 멀티모달 RAG 파이프라인 성능 향상을 위한 비순환 평가 및 검색 품질-비용에 대한 실증 연구**
- 영문 제목: **An Empirical Study of Non-circular Evaluation and Retrieval Quality-Cost for Enhancing the Performance of End-to-End Multimodal RAG Pipeline**
- 분야: 데이터베이스, 정보검색, 멀티모달 데이터 관리
- 주제어: 도시 교통 감시, 멀티모달, 벡터 데이터베이스, VLM, RAG

## 한 문장 연구 정의

대규모 도시 감시 영상에서 전체 원본을 매 질의마다 VLM에 넣는 대신, 벡터 데이터베이스 계층이 자연어 의미와 센서·시공간 조건을 이용해 소수의 검색 문맥을 선별하도록 하고, 이 계층의 저장 표현·검색 계획·검색 신호·물리 색인·배포 구조를 비순환 평가 아래 품질·지연·저장·구축 비용과 최종 VLM-QA 효과로 비교한다.

## 핵심 질문

> 평가 순환성이 차단된 실제 도시 감시 워크로드에서 벡터 데이터베이스 계층의 다섯 설계 축은 검색 품질, 질의 지연, 저장량, 색인 구축 시간 사이에 어떤 절충을 만들며, 정답 기준과 자원 제약 아래 어떤 구성을 선택해야 하는가? 또한 그 검색 개선은 어떤 조건에서 최종 VLM 답변으로 전파되는가?

## 검증 → 설계 → 전파

1. **검증(RQ1)**: 비교에 쓰는 작업 부하 자체가 정답 정보를 누설하지 않는가?
2. **설계(RQ2–RQ5)**: 무엇을 저장하고, 조건을 언제 적용하고, 어떤 신호와 색인을 쓰며, 색인을 어디에 배포할 것인가?
3. **전파(RQ6)**: 검색 단계의 향상이 실제 답변 정확도로 이어지는가?

## 여섯 연구 질문

### RQ1. 비순환 평가 타당성

같은 사람 주석에서 질의·필터·검색 문서·정답을 함께 파생하면 검색 점수는 얼마나 왜곡되는가? 센서 메타데이터, 픽셀 기반 VLM 설명문, 사람 주석을 분리한 세 원천 프로토콜은 이 왜곡을 진단하고 차단하는가?

### RQ2. 검색용 데이터 구성

영상 설명문, 대표 이미지, 이미지·설명문 결합 벡터, 다중 이미지, 설명문·이미지 이중 색인은 검색 품질·지연·저장 공간에서 어떤 절충을 만드는가?

### RQ3. 검색 계획

메타데이터 조건을 필수 제약 또는 관심 단서로 해석할 때 벡터 단독, 검색 전 조건 적용, 검색 후 조건 적용, 혼합 검색의 상대 효과는 어떻게 달라지는가? 이 효과는 조건–관련성 결합도에 따라 바뀌는가?

### RQ4. 검색 신호와 순위 융합

메타데이터, BM25 어휘, 임베딩 벡터, BM25–벡터 RRF는 비순환 조건에서 독립적인 검색 이득을 제공하는가? 약한 신호와의 융합은 강한 신호를 개선하는가, 희석하는가?

### RQ5. 물리 색인과 배포

실제 시공간 조건의 선택도와 임베딩 공간 군집성을 고려할 때 Flat, HNSW, IVF-Flat, IVF-PQ와 전역·조건별 부분 색인을 어떻게 선택해야 하는가?

### RQ6. VLM 응답 전파

관련 클립 회수와 색인 재현율 차이는 최종 VLM-QA 정확도로 얼마나 전파되는가? 코퍼스 크기, 시점 가시성, VLM 지각 능력, 질문 설계, 답변 편향은 전파를 어떻게 제한하는가?

## 논문의 핵심 답

- 평가 순환성은 알고리즘을 개선하지 않아도 nDCG@10을 `0.181 → 1.000`까지 부풀릴 수 있다.
- 다중 이미지는 의미론적 검색 품질의 가장 높은 점 추정치를 보이지만 설명문 대비 저장량 약 `2.8배`, p50 지연 약 `3배`를 요구한다.
- 메타데이터 사전 필터는 필수 제약에는 유리하지만, 관심 단서에서는 관련 결과를 조기에 누락시킬 수 있다. 효과는 조건–관련성 결합도에 조건부다.
- 실제 시공간 군집 조건은 동일 선택도의 무작위 조건보다 전역 ANN의 손실을 크게 만든다. 조건별 부분 색인이 이 손실을 대부분 회복한다.
- 좋은 검색 문맥과 좋은 카메라 시점은 답변을 개선하지만, 근사 색인 차이가 최종 답변으로 자동 전파된다는 주장은 현재 표본에서 확립되지 않았다.
- 따라서 단일 최적 구성은 없으며, **정답 계약과 SLA를 먼저 정한 뒤 파레토 후보를 선택**해야 한다.

## 읽는 순서

`평가가 믿을 만한가(RQ1)` → `무엇을 저장할까(RQ2)` → `필터를 언제 걸까(RQ3)` → `무엇으로 순위를 매길까(RQ4)` → `어떤 색인을 어디에 둘까(RQ5)` → `최종 답이 좋아지는가(RQ6)` 순서로 읽는다.


# 1. 서론 — 연구 동기와 공헌

## 왜 도시 감시 영상 검색이 필요한가

교차로 신호 운영, 사고 대응, 보행자·이륜차 등 교통약자 보호를 위해 감시 영상은 계속 축적된다. 실무 질의는 “오전 10시경 오토바이 두 대가 등장한 장면”처럼 자연어 의미와 시간·장소·센서 조건을 동시에 포함한다. 사람의 수작업 검토는 데이터 증가 속도를 감당하기 어렵다.

## 왜 전체 영상을 VLM에 직접 넣을 수 없는가

질의마다 모든 영상이나 프레임을 VLM에 제공하면 문맥 길이 한계를 넘고 GPU 비용이 폭증한다. 현실적인 파이프라인은 먼저 데이터베이스가 전체 코퍼스에서 상위 `k`개 클립·프레임·설명문을 검색하고, VLM은 이 제한된 검색 문맥만 보고 답한다.

따라서 병목은 단지 VLM 모델 성능이 아니다. 다음 데이터베이스 설계가 검색 품질과 비용을 함께 결정한다.

- 어떤 형태의 검색용 데이터를 저장하는가
- 메타데이터 조건을 검색 전·후 또는 탐색 중 언제 적용하는가
- 어휘·벡터·시각 신호를 어떻게 결합하는가
- 어떤 물리 색인을 사용하는가
- 전체 또는 조건별 어느 범위에 색인을 배포하는가

## 기존 평가가 가진 더 근본적인 문제

영상 벤치마크에서 질의, 필터 조건, 검색 문서, 정답 집합이 같은 사람 주석에서 파생될 수 있다. 이 경우 검색기가 영상을 잘 이해해서가 아니라 정답 정보가 조건이나 문서에 되풀이되어 높은 점수를 얻는다.

예를 들어 정답 클립만 통과하는 조건을 만들면 후보 집합이 곧 정답 집합이 된다. 정답 라벨 문구를 검색 문서에 다시 쓰면 BM25는 영상을 보지 않고도 질의와 같은 단어를 찾아 높은 순위를 매긴다. 이런 평가는 실제 운영 성능이 아니라 데이터 생성 과정의 중복을 측정한다.

## 연구 목표

1. 센서 기록, 영상 픽셀 기반 설명문, 사람 주석을 분리해 비순환 작업 부하를 확립한다.
2. 저장 방식·필터 계획·검색 신호·물리 색인·배포를 한 파이프라인에서 비교한다.
3. 검색 개선이 최종 VLM 답변으로 전달되는 조건과 한계를 검증한다.

## 논문의 세 가지 공헌

1. **평가 공헌**: 세 원천을 독립 분리하고 직접 누수를 자동 검사하는 비순환 평가 프로토콜을 수립한다. 정답 조건 및 라벨 재진술을 통제 주입해 점수 부풀림의 인과 효과를 정량화한다.
2. **데이터베이스 설계 공헌**: 검색용 데이터, 조건 적용, 검색 신호, 물리 색인, 배포를 품질·지연·저장·구축 비용으로 통합 비교한다.
3. **종단 간 공헌**: 데이터베이스 검색 개선과 최종 답변 사이에 증거 회수, VLM 인식, 질문·답변 편향이라는 전파 경계가 있음을 밝힌다.

## 반드시 지켜야 할 연구 범위

이 연구는 실시간 CCTV 스트리밍 시스템 전체를 구현한 연구가 아니다. 프레임 전수 캡션화, 비동기 임베딩 큐, delta 검색, 자동 hot/cold 전환, 동시 질의 부하는 실제 배치에 필요하지만 본 연구에서는 오프라인 설계 근거를 제공하는 범위에 머문다.

또한 “검색 품질이 좋아지면 답변도 반드시 좋아진다”, “필터는 항상 좋다/나쁘다”, “다중 이미지가 항상 최적이다”와 같은 무조건적 결론을 허용하지 않는다.


# 2. 관련 연구와 연구 공백

## 2.1 데이터 누수와 평가 순환성

데이터 누수는 평가 대상이 맞혀야 할 목표 정보가 입력 특징이나 평가 자료에 다시 들어가 실제 운용보다 높은 성능을 만드는 현상이다. 평가 순환성은 도구나 모델을 만드는 데 사용한 자료와 평가 기준의 생성 경로가 겹쳐 상대 비교를 왜곡하는 구조적 문제다.

본 연구는 이 개념을 벡터 데이터베이스 작업 부하로 확장한다. 검색 문서·질의·필터·정답 집합이 같은 주석 계보를 공유하면 검색기의 장면 이해와 평가 자료가 제공한 힌트를 분리할 수 없다. 해결 방법은 단순 텍스트 중복 제거가 아니라 생성 원천의 분리와 재사용 금지, 자동 감사다.

## 2.2 멀티모달·비디오 RAG

RAG는 외부 자료를 먼저 검색하여 생성 모델의 입력에 제공한다. VideoRAG는 이를 영상 코퍼스로 확장한다. CLIP 계열 모델은 이미지와 텍스트를 공통 임베딩 공간에 배치해 자연어–이미지 검색을 가능하게 한다.

기존 연구의 주요 관심은 검색 결과를 생성 모델에 잘 전달하거나 표현 모델의 정확도를 높이는 것이다. 본 연구는 검색용 데이터를 데이터베이스에 물질화된 실체로 보고, 표현의 저장량·색인 크기·구축 시간·질의 지연까지 함께 측정한다.

## 2.3 Filtered Vector Search와 벡터 데이터베이스

VBASE, ACORN, pgvector, Milvus, Weaviate 등은 구조화 조건과 벡터 유사도 검색을 결합한다. 핵심은 필터를 검색 전, 검색 후, 또는 ANN 탐색 중에 적용하는 실행 계획과 물리 색인이다.

기존 벤치마크는 선택도만 맞춘 무작위 마스크를 자주 사용한다. 그러나 실제 장소·시간 조건은 임베딩 공간에서 군집될 수 있으므로 같은 선택도라도 그래프 또는 군집 탐색을 훨씬 어렵게 만든다. 본 연구는 실측 조건과 동일 선택도의 무작위 대조군을 짝지어 이 차이를 분리한다.

## 2.4 도시 감시 영상-언어 이해

VRU-Accident, UCA/UCF-Crime, MEVA, 다각도 CCTV, Spatialyze 계열 연구는 사고·이상행동·시공간 조건을 영상 질의 또는 VQA와 연결한다. 이들은 도메인 타당성과 질문·답변 과제를 제공하지만, 데이터 원천 분리와 데이터베이스 물리 설계의 통합 비교가 주목적은 아니다.

## 2.5 논문이 메우는 공백

기존 연구는 다음 축을 개별적으로 다뤘다.

- 영상 검색과 VLM 답변
- 필터 결합 벡터 검색
- 임베딩과 멀티모달 표현
- ANN 색인 성능
- 데이터 누수와 평가 타당성

본 연구는 이들을 `원천 분리 → 검색용 데이터 저장 → 조건 계획 → 신호 결합 → 물리 색인·배포 → 최종 답변`이라는 하나의 종단 파이프라인에서 연결한다. 핵심 차별점은 새로운 검색 모델 하나를 제안하는 것이 아니라, **어떤 데이터베이스 설계를 어떤 평가 계약과 자원 조건에서 선택해야 하는지**를 실증적으로 제시한다는 점이다.

## 선행 연구를 읽을 때의 질문

- 필터와 정답이 같은 주석에서 나오지 않았는가?
- 검색 문서가 정답 문구를 재진술하지 않았는가?
- 무작위 선택도 실험이 실제 시공간 군집을 대변하는가?
- 정확도만 보고 저장·구축·지연 비용을 누락하지 않았는가?
- 검색 지표 상승을 답변 정확도 상승으로 바로 해석하지 않았는가?

# 3. 문제 정의와 비순환 평가 계약

## 분석 단위와 입력·출력

- 기본 저장·검색·정답 판정 단위는 데이터셋이 배포한 `mp4` 영상 파일 하나인 **클립**이다.
- 입력 질의는 자연어 의미 조건과 메타데이터 조건을 함께 가진다.
- 데이터베이스 출력은 상위 `k`개 클립·프레임·설명문의 순위 목록이다.
- 이 목록을 VLM 입력으로 구성한 것을 **검색 문맥(retrieved context)**이라 한다.
- 검색 정답은 qrels에 기록된 관련 클립 집합이다.

## ‘증거’라는 말의 세 대상

| 구분 | 정확한 명칭 | 의미 |
|---|---|---|
| DB 출력 | 상위 `k` 검색 결과 | 클립·프레임·설명문의 순위 목록 |
| VLM 입력 | 검색 문맥 | 검색 결과를 모델 입력 형식으로 구성한 집합 |
| 평가 대상 | 관련 클립 / qrels | 정답 기준을 만족하는 클립 |

세 대상을 모두 “증거”라고 부르면 DB 검색 성공, VLM 입력 구성, 정답 판정이 혼동된다. 문서에서는 가능한 한 위 명칭을 구분한다.

## 벡터 데이터베이스 계층

영상에서 파생된 설명문, 이미지 임베딩 벡터, 센서 메타데이터를 저장·색인하고, 자연어 의미 조건과 메타데이터 조건을 받아 필터링·어휘 검색·벡터 검색·순위 융합을 수행해 상위 검색 결과를 반환하는 계층이다. Faiss·Milvus·Weaviate 같은 전용 엔진과 PostgreSQL/pgvector 같은 관계형 확장을 모두 포괄한다.

## 비순환 세 원천 프로토콜

| 평가 구성 요소 | 허용된 생성 원천 | 금지되는 재사용 |
|---|---|---|
| 메타데이터 predicate | 센서 기록·독립 구조화 메타데이터 | 사람 정답 라벨을 필터로 변환 |
| 검색 문서 | 영상 픽셀만 본 VLM 설명문 또는 시각 임베딩 | 정답 정의·라벨·내부 정답 필드 삽입 |
| relevance / qrels | 독립 사람 주석 | 검색 문서의 모델 출력을 정답으로 재사용 |

프로토콜은 특정 데이터셋 이름이 아니라 데이터를 만드는 규칙이다. AI Hub 교차로는 이 규칙으로 구축한 주 평가 산출물이고, VRU-Accident와 지능형 관제 CCTV의 수정 전후 비교는 같은 규칙을 기존 작업 부하에 이식한 사례다.

## 순환성의 두 주요 경로

### C1. Filter–answer circularity

정답 집합 또는 정답을 정의한 속성을 필터 조건으로 사용하면 필터 통과 집합이 곧 정답 집합이 된다. 이후 벡터 순위가 무의미해져도 nDCG가 구조적으로 높아진다.

### C2. Document–answer circularity

사람 정답 라벨의 정의 문장을 검색 문서에 재진술하면 질의와 문서의 어휘·의미 중복이 인위적으로 커진다. 특히 BM25는 장면을 이해하지 않고도 직접 단어 일치로 높은 순위를 얻는다.

## 이중 정답 계약

| 항목 | 엄격한 정답(strict) | 의미론적 정답(semantic) |
|---|---|---|
| 조건 해석 | 필수 제약(hard constraint) | 관심 단서(soft cue/intent) |
| 정답 정의 | 의미 관련성 ∩ 메타데이터 조건 | 의미 관련성을 만족하는 모든 클립 |
| 출처 | 사람 주석 ∩ 센서 기록 | 사람 주석 |
| 평가 목적 | 명시 조건 준수 | 의미상 유용한 결과의 조기 누락 진단 |
| 제출본 규모 | qrels 6,809행 | qrels 24,872행 |

엄격한 정답에서 사전 필터가 유리한 것은 부분적으로 정의상 자명하다. 반대로 의미론적 정답은 센서 조건과 무관해도 의미상 관련된 클립을 인정하므로 사전 필터의 조기 누락을 드러낸다. 따라서 두 기준을 분리하지 않은 평균은 필터의 효과를 해석하기 어렵다.

## 조건–관련성 결합도

메타데이터 조건 충족 여부와 의미 관련성 여부가 함께 나타나는 정도를 Cramér's `V`로 측정한다.

- `V < 0.3`: 저결합. 조건이 의미 관련성을 잘 예측하지 못하므로 사전 필터가 관련 결과를 잘라낼 수 있다.
- `V ≥ 0.3`: 고결합. 조건이 의미 관련성과 함께 움직여 사전 필터가 후보를 줄이면서 관련 결과를 보존할 가능성이 높다.

예를 들어 `황색 신호 여부 × 주차 차량`은 낮은 결합을 보일 수 있지만, `센서 교통 밀도 × 화면 내 개체 20개 이상`은 자연스럽게 결합될 수 있다.

## 자동 감사(A6)의 목적

자동 감사는 최소한 다음을 확인해야 한다.

1. predicate, document, relevance의 출처가 분리되어 있는가?
2. 메타데이터에 정답 라벨이나 내부 정답 필드가 포함되지 않았는가?
3. 검색 문서가 정답 라벨·정의 문구를 직접 노출하지 않는가?
4. 질의 템플릿이 정답 문장을 그대로 복사하지 않는가?
5. qrels와 문서·조건 사이의 직접 키 조인이 차단되었는가?

자동 검사 통과는 모든 의미적 누수를 완전히 부정하는 증명은 아니지만, 직접적인 생성 경로 재사용을 재현 가능하게 차단하는 최소 계약이다.

AI Hub 교차로 데이터의 세 채널은 다음과 같이 결합된다.

- 센서 카메라 채널: 시간·신호·교통량이 기록된 클립 `32,880개`
- 시각 카메라 채널: 영상 클립 `52,462개`
- 사람 주석과 연결된 시각 클립: `52,210개`
- 동일 교차로에서 촬영 시각 차이 `±120초` 이내의 가장 가까운 센서 클립을 연결해 확보한 시각 클립: `47,098개`
- 통제 설계 비교용 최종 코퍼스: 영상 설명문 `3,000개`

각 클립의 중간 이미지를 VLM에 넣어 교통량, 차종, 정차·주차 차량, 보행자, 도로, 날씨 중 화면에서 보이는 내용을 2–4문장으로 설명한다. 생성 모델에는 픽셀과 프롬프트만 제공하고 센서 기록과 사람 주석은 제공하지 않는다.

## 4.2 질의 85개 구축

메타데이터의 구체 조건값 `22개`와 의미 조건 `5종`을 교차해 후보 `110개`를 만든다.

| 메타데이터 범주 | 조건값 |
|---|---|
| 시간대 | morning, afternoon, evening |
| 황색 신호 | true, false |
| 보행 신호 | true, false |
| 센서 교통 밀도 | low, mid, high |
| 특정 시각 | 6, 7, 8, 9, 13, 14, 15, 16, 17, 18, 19, 20시 |

의미 조건은 주차 차량, 화면 내 개체 20개 이상, 버스 2대 이상, 정차 차량, 이륜차 2대 이상이다. 두 조건을 동시에 만족하는 양성 클립이 5개 이상인 조합 `85개`를 최종 질의로 확정한다.

## 4.4 검색용 데이터 구성 — RQ2

| 구성 | 물질화 방식 | 클립당 벡터/색인 | 핵심 절충 |
|---|---|---:|---|
| 영상 설명문 | 클립을 요약한 텍스트 임베딩 | 1 | 저비용 기준선, 캡션 누락에 민감 |
| 대표 이미지 | 중간 또는 대표 프레임의 시각 임베딩 | 1 | 텍스트 없이 시각 신호 사용 |
| 이미지·설명문 결합 | 두 모달리티를 한 벡터로 융합 | 1 | 동일 벡터 예산의 중간 후보 |
| 다중 이미지 | 클립의 주요 프레임 여러 장을 각각 저장 | 최대 3 | 시간적·시각적 포괄성 증가, 저장·지연 증가 |
| 이중 색인 | 설명문 색인과 다중 이미지 색인을 별도 검색 후 RRF | 1+최대 3 | 모달리티 보존, 가장 높은 운영 비용 |

## 4.5 검색 계획 — RQ3

| 계획 | 처리 순서 | 장점 | 위험 |
|---|---|---|---|
| 벡터 단독 | 전체 코퍼스 의미 검색 | 의미상 관련 결과 보존 | 명시 조건 위반 가능 |
| 검색 전 조건 적용 | predicate → 부분집합 → 벡터 검색 | 필수 제약 보장, 후보 축소 | 관련 결과 조기 누락 |
| 검색 후 조건 적용 | 전체 벡터 top-200 → predicate 제거 | 넓은 의미 탐색 유지 | 필터 탈락이 많으면 top-k 부족 |
| 혼합 검색 | 사전 필터 → BM25·벡터 → RRF | 어휘·의미 결합 가능 | 약한 신호가 강한 순위를 희석 |

논문의 검색 계획 비교에서 혼합 검색은 텍스트 설명문에만 적용 가능하다. 따라서 유효한 데이터–계획 조합은 `1×4 + 4×3 = 16개`다.

## 4.6 검색 신호와 순위 융합 — RQ4

- 메타데이터 단독: 조건 통과 클립을 식별자 순으로 반환하는 결합도 기준선
- BM25: 질의와 설명문의 정확한 어휘 일치를 이용하는 sparse 검색
- 벡터: 임베딩 공간의 dense 의미 유사도를 이용
- BM25–벡터 RRF: 서로 다른 점수 대신 순위 역수를 합산

설명문 색인과 이미지 색인의 RRF인 “이중 색인”은 RQ2의 저장 구성이다. BM25와 벡터 신호를 결합하는 RRF는 RQ4의 검색 신호다. 같은 RRF라도 비교하려는 설계 축이 다르므로 혼동하면 안 된다.

## 4.7 물리 색인과 배포 — RQ5

| 색인 | 원리 | 대표 조절값 |
|---|---|---|
| Flat | 모든 벡터를 전수 비교하는 정확 검색 | 없음 |
| HNSW | 계층적 근접 그래프를 따라 탐색 | `M`, `efConstruction`, `efSearch` |
| IVF-Flat | 벡터를 군집화하고 일부 inverted list만 검색 | `nlist`, `nprobe` |
| IVF-PQ | IVF에 product quantization을 결합해 벡터 압축 | `m`, 비트 수, `nprobe` |

제출본 통합 격자는 Flat, HNSW `efSearch={64,256}`, IVF 계열 `nprobe={8,32}` 등 총 `7개` 물리 설정을 사용한다. 유효 데이터–계획 조합 `16개`와 결합해 `112개 구성`을 만든다.

배포 범위는 전체 데이터를 하나로 묶는 전역 색인과 자주 쓰는 조건별 부분집합만 별도로 색인하는 조건별 부분 색인을 핵심 비교로 삼는다. local/hot/cold는 운영 정책의 확장 개념이며, 제출본은 자동 동적 운영 전체를 구현한 것이 아니다.

## 온라인·오프라인 계측 경계

- 온라인 지연 포함: 검색, 조건 적용, 후보 통합, RRF, top-k 반환
- 온라인 지연 제외: 캡션 생성, 코퍼스 임베딩, 질의 임베딩 생성
- 오프라인 비용 별도 보고: 직렬화 색인 크기, 색인 구축 시간, 임베딩·문서 생성 비용

절대 지연 시간은 장비·스레드·API 왕복 범위에 민감하다. 따라서 같은 엔진과 같은 측정 경계 안에서 상대 비교해야 한다.

## nDCG@10

순위가 높은 관련 결과에 더 큰 가치를 주고, 이상적 순위로 정규화한 정보검색 지표다.

$$
DCG@k = \sum_{i=1}^{k}\frac{2^{rel_i}-1}{\log_2(i+1)}, \qquad
nDCG@k = \frac{DCG@k}{IDCG@k}
$$

- `1`에 가까울수록 관련 클립이 상위에 잘 정렬된다.
- 정답 후보만 남기는 오라클 필터에서는 구조상 `1.0`이 될 수 있으므로 모델 성능으로 해석하면 안 된다.
- 논문은 주로 이진 relevance이지만 정의는 graded relevance에도 적용된다.

## Recall@10

$$
Recall@10 = \frac{|\text{top-10 검색 결과} \cap \text{관련 클립}|}{|\text{관련 클립}|}
$$

VLM이 볼 수 있는 문맥이 top-10으로 제한될 때 관련 결과의 누락 정도를 나타낸다. RQ5에서는 별도로 Flat 정확 검색의 top-10을 기준으로 한 **상대 ANN recall/fidelity**를 사용해 의미 채점과 색인 손실을 분리한다.

## MRR과 Hit@k

- MRR: 첫 번째 관련 결과의 순위 역수 평균. 최초 관련 결과를 얼마나 빨리 보여주는지 측정한다.
- Hit@k: 상위 `k` 안에 관련 결과가 하나라도 있는 질의의 비율이다.

Note의 공통 지표로 이해할 필요가 있지만, 제출본의 핵심 표는 nDCG@10과 Recall@10을 중심으로 보고한다.

## p50과 p95 지연

- p50: 질의 지연의 중앙값. 전형적인 사용자 경험을 나타낸다.
- p95: 95%의 질의가 이 값 이하에서 끝난다. 꼬리 지연과 SLA 위험을 나타낸다.

평균만 보고하면 소수의 느린 질의를 숨길 수 있으므로 p50과 p95를 함께 본다.

## 효과량 Δ

두 방법의 대응 질의별 점수 차이 또는 처리군–기준선의 차이다.

$$
\Delta = metric(\text{treatment}) - metric(\text{baseline})
$$

양수인지 여부뿐 아니라 크기와 신뢰구간, 비교 단위가 질의인지 조건–의미 쌍인지 확인해야 한다.

## Bootstrap 95% 신뢰구간

정규분포를 강하게 가정하지 않고 관측 단위를 복원 추출하여 효과량의 표본 분포를 근사한다.

- query bootstrap: 질의를 재표집한다.
- cluster bootstrap: 같은 `relevance 정의 × facet`에 속한 질의의 의존성을 보존하기 위해 군집 단위로 재표집한다.

cluster CI가 0을 포함하면 query CI만으로 보편 효과를 확정하지 않는다. 신뢰구간은 “95% 확률로 참값이 이 안에 있다”는 베이지안 문장이 아니라, 같은 절차를 반복했을 때 구간 생성법의 장기 포함률을 뜻한다.

## Wilcoxon 부호순위 검정

같은 질의를 두 방법으로 평가한 대응 차이가 0을 중심으로 대칭인지 비모수적으로 검정한다. 정규성 가정이 어려운 검색 지표의 대응 비교에 사용한다. 효과량과 CI 없이 p-value만 보고하면 안 된다.

## Spearman 순위상관

두 변수 사이의 단조 관계를 순위로 측정한다. RQ3에서는 Cramér's `V`가 커질수록 사전 필터 효과 Δ가 증가하는 경향을 본다. 상관은 인과가 아니며, 군집 CI와 표본 분포를 함께 확인한다.

## Cramér's V

두 범주형 변수의 결합 강도를 `0`–`1` 범위로 나타낸다.

$$
V = \sqrt{\frac{\chi^2}{n\,\min(r-1,c-1)}}
$$

본 연구에서는 predicate 충족 여부와 의미 관련성의 결합도로 사용하며 `0.3`을 사전 층화 경계로 둔다. 경계값은 절대적 자연법칙이 아니라 이 연구의 분석 계약이다.

## 다중 비교 보정

112개 구성처럼 비교가 많으면 우연히 작은 p-value가 나올 확률이 커진다.

- Holm 보정: 사전에 정한 주요 비교에서 family-wise error rate를 강하게 제어한다.
- Benjamini–Hochberg(BH): 탐색적 비교에서 기대 거짓 발견 비율(FDR)을 제어한다.

“보정 전 유의”와 “보정 후 유의”를 구분해야 한다. 예를 들어 RQ2의 다중 이미지 점 추정치는 높지만 storage-family cluster BH `q=0.112`이므로 모든 환경의 보편 우위로 부르지 않는다.

## 파레토 최적과 SLA

어떤 구성이 다른 구성보다 품질은 낮고 비용은 더 크다면 지배당한다. 반대로 어느 한 축을 개선하려면 다른 축을 희생해야 하는 비지배 구성들의 경계가 파레토 전선이다.

실제 선택 순서는 다음과 같다.

1. strict 또는 semantic 정답 계약을 정한다.
2. 최소 품질과 p95 지연 상한을 SLA로 정한다.
3. 저장·구축 예산을 정한다.
4. 이를 만족하는 파레토 후보에서 선택한다.

### 필수 제약과 관심 단서

strict에서는 사전 필터 `0.157`이 벡터 단독 `0.059`보다 `+0.0983`, 95% CI `[+0.068,+0.133]` 높다. 그러나 정답 정의 자체가 predicate 만족을 요구하므로 조건을 먼저 적용할 때 유리한 것은 상당 부분 자명하다.

semantic에서는 벡터 단독 `0.170`이 가장 높고 사전 필터 `0.154`, 사후 필터 `0.150`, 혼합 검색 `0.133` 순이다. 사전 필터–벡터 단독의 통합 차이 `−0.0158`, CI `[−0.047,+0.015]`는 0을 포함한다. “필터가 해롭다”가 아니라 전체 평균에서 뚜렷한 차이가 확립되지 않았다는 뜻이다.

- 고결합 관심 단서: 사전 필터의 품질·지연 동시 이득 가능성을 시험한다.

## RQ4. 검색 신호와 순위 융합

### 네 신호의 비교

- 메타데이터 단독: strict `0.218`, semantic `0.217`
- BM25: strict `0.017`, semantic `0.050`
- 벡터 단독: strict `0.059`, semantic `0.170`
- 사전 필터 후보에서 BM25–벡터 RRF: semantic `0.133`, 같은 후보의 벡터 단독 `0.154`

메타데이터 단독의 높은 점수는 ID 순위화가 우수하다는 뜻이 아니라 조건과 정답의 결합이 강하다는 뜻이다. 라벨 재진술을 제거한 뒤 BM25는 약했고, 이를 RRF로 섞자 벡터 단독보다 성능이 낮아졌다.

### RRF의 핵심 원리

서로 다른 검색기의 점수 척도는 직접 더하기 어렵다. RRF는 각 결과의 순위만 이용한다.

$$
RRF(d) = \sum_{r\in R}\frac{1}{k + rank_r(d)}
$$

논문은 상수 `k=60`을 사용한다. RRF는 신호를 자동으로 개선하는 마법이 아니며, 약한 입력 순위도 일정한 투표권을 갖기 때문에 좋은 순위를 희석할 수 있다.

### 지식그래프 재조합 보조 실험

센서 조건과 설명문 개체로 만든 지식그래프에서 특정 개체가 정답일 확률을 높이는 Lift 중앙값은 `0.002`였다. KG 순위의 strict nDCG@10 `0.176`은 메타데이터 단독 `0.218`보다 낮았다. 세 원천 규칙 때문에 새 정답 채널을 KG에 넣을 수 없고, 캡션 개체와 센서 조건을 재조합한 것만으로는 새로운 판별 신호가 되지 않았다.

### RQ4 결론

비순환 평가에서 BM25, BM25–벡터 RRF, 현재 KG 재조합은 독립 이득을 보이지 않았다. 이는 모든 hybrid retrieval이 나쁘다는 일반 명제가 아니다. **융합 전에 각 신호의 독립 품질과 상보성을 검증해야 하며, 약한 신호를 무조건 섞지 말라**는 결과다.


# 5.2.5 실험 결과 — RQ5 물리 색인과 배포

## 왜 무작위 마스크만으로 부족한가

선택도(selectivity)는 전체 데이터 중 조건을 통과하는 비율이다. 선택도가 같아도 실제 장소·시간 조건의 벡터는 임베딩 공간에 군집될 수 있지만, 무작위로 고른 벡터는 전체 공간에 흩어진다. HNSW 그래프와 IVF 군집 탐색은 이 공간 구조에 영향을 받으므로 같은 5% 조건이라도 재현율이 달라진다.

## 실측 조건과 동일 선택도 무작위 조건

아래 Δ는 `무작위 조건 recall − 실측 조건 recall`이다. 양수가 클수록 무작위 벤치마크가 실제 성능을 과대평가한다.

## 조건별 부분 색인

조건별 부분집합에 HNSW 또는 Flat을 구축하면 전역 탐색에서 생긴 군집 손실을 제거할 수 있다. canonical의 추가 검증에서 partial recall은 대체로 `0.981–0.995`, MIRIS 이식에서는 `0.998–1.000`이었고 p50은 약 `0.34–0.49ms`였다.

그러나 모든 조건에 부분 색인을 만들면 메모리와 갱신 비용이 폭증한다. 구축 손익분기는 다음처럼 생각한다.

$$
N^* = \frac{\text{부분 색인 구축 비용}}{\text{전역 경로 1회 비용} - \text{부분 색인 1회 비용}}
$$

다음 갱신 시점 전 예상 질의 수가 `N*`보다 크고, 전역 경로가 목표 recall `0.95`를 만족하지 못하거나 지연 SLA를 위반할 때 부분 색인을 배포한다.

## RQ5 운영 정책

1. Flat을 기준으로 각 predicate의 실제 ANN recall을 측정한다.
2. 동일 선택도의 무작위 마스크가 아니라 실제 장소·시간 조건을 사용한다.
3. 전역 recall이 `0.95` 이상이면 전역 HNSW/IVF 경로를 유지한다.
4. 낮은 선택도·강한 군집으로 recall이 무너지면 조건별 부분 HNSW 또는 Flat을 사용한다.
5. 부분 색인은 예상 질의 빈도가 구축·갱신 손익분기를 넘는 hot predicate에만 만든다.
6. 저빈도 cold predicate는 전역 경로 또는 정확 검색 fallback으로 처리한다.

## 결론의 정확한 범위

“부분 색인이 언제나 최적”이 아니다. **실제 predicate 분포에서 전역 ANN이 SLA를 위반하고, 그 조건의 반복 질의가 구축비를 상각할 때** 부분 색인이 타당하다. 병목은 데이터와 엔진에 따라 recall 손실 또는 fallback 지연으로 달라질 수 있다.


# 5.2.6 실험 결과 — RQ6 VLM 응답 전파

| oracle | 0.7467 | 0.6900 |

> **역할 주의:** Llama-3-8B는 이 RQ6에서 답변을 생성하는 대조 생성기다. Prometheus·gpt-oss와 함께 구성된 독립 판정기 패널이 아니며, `19,400건`을 재채점한 judge라는 기록은 제출 PDF와 canonical 실험 문서에 없다.

두 생성기 모두 큰 증거 사다리 순서는 재현하지만 Llama의 oracle−vector 차이는 작고 비유의다. 이는 검색 문맥의 잠재 이득이 생성 모델 능력에 의해 제한될 수 있음을 보여준다.

## 실험 B. 다중 카메라 시점

다각도 CCTV에서 동일 사건의 잘 보이는 시점, 잘 보이지 않는 시점, 두 시점을 동시에 제공하는 조건을 비교한다.

- 잘 보이는 단일 시점은 답변 정확도를 최대 `+15.2%p` 높였다.
- 두 시점을 동시에 제공해도 잘 보이는 단일 시점보다 추가 이득이 관찰되지 않았다.
- 더 많은 이미지가 항상 더 좋은 검색 문맥은 아니다. 핵심 객체가 잘 보이는 시점을 고르는 것이 중복·무관 시점을 늘리는 것보다 중요하다.

## 실험 C. ANN 차이의 답변 전파

143K 프레임 코퍼스에서는 색인 설정에 따라 ANN recall 차이가 있었지만, 정답 증거가 top-k에 적중한 표본과 답변 변화 표본이 충분하지 않았다. 제출본은 이 결과를 탐색적으로만 보고한다.

canonical 미니 파일럿에서도 mediator hit rate는 `0.1222 → 0.0556`으로 변했지만, hit 조건 정확도 `0.5625`와 no-hit 조건 정확도 `0.5823`의 차이가 뚜렷하지 않았다. exact−strong answer accuracy는 `+0.028`에 그쳤고 신뢰구간이 넓었다.

## 왜 전파가 막히는가

### 코퍼스·검색 경계

소형 코퍼스에서는 Flat, HNSW, IVF가 거의 같은 결과를 반환한다. 원인인 색인 선택이 중개 변수인 증거 적중률을 바꾸지 못하면 답변도 달라지지 않는다.

### 지각 경계

정답 프레임이 들어와도 작은 이륜차, 신호등 상태, 가려진 객체를 VLM이 못 보면 답은 개선되지 않는다. 단일 프레임으로 이동 방향·사고 전후 관계를 묻는 질문은 관측 자체가 불충분하다.

### 답변 편향

프레임에 특정 객체가 보이면 실제 질문 정답과 무관하게 “예”를 선택하는 content-induced bias가 생길 수 있다. 무관한 검색 문맥이 closed-book보다 높아지는 현상도 문맥 품질 외의 과제·선택지 효과를 의심하게 한다.

### 증거 양과 적합성

증거를 많이 주면 정답 포함 확률은 높아지지만 중복·무관 정보가 VLM을 방해할 수 있다. `적은 고품질 증거`, `많은 혼합 품질 증거`, `중복 프레임`, `상보 시점`을 구분해야 한다.

## RQ6 결론

- 관련 설명문과 가시성이 좋은 시점은 답변 개선과 연결된다.
- 검색 계획의 작은 차이와 ANN recall 차이가 최종 답변으로 전파된다는 인과 주장은 현재 표본에서 확립되지 않았다.
- 종단 평가에서는 `색인 선택 → top-k 변화 → 정답 증거 적중 → VLM 인식 → 답변 변화`를 단계별로 측정해야 한다.


# 5.3–6. 교훈, 한계, 결론과 재현 주의

## 실무 설계 순서

1. 질의·조건·문서·qrels의 생성 계보를 감사해 순환성을 먼저 차단한다.
2. 메타데이터 조건이 필수 제약인지 관심 단서인지 정한다.
3. strict와 semantic 정답 계약을 분리해 측정한다.
4. 검색용 데이터 표현의 품질·p50/p95·저장량을 함께 비교한다.
5. 실제 predicate와 동일 선택도의 무작위 predicate를 짝지어 ANN 손실을 측정한다.
6. Flat 대비 recall과 SLA를 만족하는 전역 색인을 먼저 찾는다.
7. 실패하는 hot predicate에만 조건별 부분 색인을 배포한다.
8. 검색 결과가 실제 top-k와 VLM 입력, 최종 답변을 바꾸는지 단계별로 검증한다.

## 조건부 의사결정 표

| 상황 | 우선 후보 | 반드시 확인할 위험 |

## 연구의 핵심 교훈

- 정답 정보 누수가 있는 높은 점수보다 비순환 조건의 낮은 점수가 더 유용하다.
- 필터의 가치는 선택도 하나가 아니라 질의 계약과 조건–관련성 결합도에 달려 있다.
- 저장 표현의 품질 우위는 비용과 통계적 불확실성을 함께 보고 해석해야 한다.
- 실제 시공간 군집을 무시한 random-mask 벤치마크는 filtered-ANN 손실을 크게 과소평가할 수 있다.
- 검색 단계 최적화와 최종 답변 최적화는 같은 문제가 아니다.

## 타당성 위협

### 구성 타당성

- strict qrels는 메타데이터 조건을 정의에 포함하므로 사전 필터에 구조적 이점이 있다.
- semantic qrels도 사람 주석의 범위와 누락에 의존한다.
- VLM 설명문은 화면의 미세 객체·부정·시간 변화를 누락할 수 있다.

### 내적 타당성

- 인코더와 표현을 동시에 바꾸면 표현 효과와 모델 효과가 섞인다.
- warm-up, 캐시, 스레드, DB 왕복 경계가 지연 결과에 영향을 준다.
- 검색 문맥 자체가 답변 선택 편향을 만들 수 있다.

### 외적 타당성

- 주 평가 코퍼스는 3,000클립으로 실제 24시간 관제 규모보다 작다.
- UCA는 독립 센서 채널이 없어 완전한 tri-source가 아닌 2.5-channel 이식이다.
- 고결합 질의와 RQ6 증거 적중 표본이 적다.
- 엔진의 fallback·planner 정책은 버전과 데이터 분포에 따라 달라진다.

### 통계적 결론 타당성

- 질의들이 같은 조건–의미 쌍을 공유해 독립이 아닐 수 있다.
- 112개 구성의 다중 비교에서 1종 오류가 증가한다.
- 작은 RQ6 차이는 검정력이 부족해 “효과 없음”과 “미확립”을 구분해야 한다.

### 시스템 범위

- 실시간 스트리밍 적재, 동시 부하, 자동 부분 색인 생성·갱신·폐기는 구현하지 않았다.
- 캡션·임베딩 생성의 GPU 비용은 온라인 검색 지연에서 제외됐다.
- 원본 영상 보존과 개인정보·보안·감사 정책은 별도 운영 문제다.

## 향후 연구

- 고결합 조건–의미 쌍과 정답 증거 적중 표본 확대
- 실시간 영상 유입·메타데이터 변경·동시 질의가 포함된 동적 작업 부하
- 조건별 부분 색인의 생성·갱신·폐기 자동화
- 여러 VLM과 벡터 DB 엔진의 종단 지연·비용 비교
- 시간 관계를 포함하는 클립·프레임 패킷 설계와 답변 편향 통제

## 최종 결론

본 연구는 메타데이터 조건, 픽셀 기반 검색 문서, 사람 qrels를 독립 생성해 벡터 데이터베이스 평가의 순환성을 차단했다. 통제 주입으로 정답 정보 재사용이 nDCG를 심각하게 부풀림을 확인했다. 이 토대에서 검색용 데이터, 조건 계획, 신호, 물리 색인과 배포를 비교한 결과 최적 구성은 정답 계약·실제 데이터 분포·자원 제약에 따라 달라졌다. 관련 설명문과 좋은 시점은 VLM 답변에 도움이 됐지만 ANN 차이의 답변 전파는 아직 미확립이다.

따라서 핵심 설계 원칙은 다음 한 문장으로 정리된다.

> **먼저 비순환 평가 계약을 확립하고, 실제 predicate 분포에서 품질·지연·저장·구축 비용의 파레토 후보를 선택한 뒤, 그 선택이 최종 답변까지 전파되는지를 별도 단계로 검증하라.**

# 전문 기술 및 통계 용어집

## A. 시스템·멀티모달 용어

### RAG

Retrieval-Augmented Generation. 질의와 관련된 외부 자료를 먼저 검색하고 그 자료를 생성 모델 입력에 추가해 답변을 만드는 구조다. 검색 실패와 생성 실패를 분리해 측정해야 한다.

### Multimodal RAG

텍스트뿐 아니라 이미지·비디오·오디오·센서 메타데이터 등 여러 모달리티를 검색과 생성에 함께 사용하는 RAG다.

### VLM / VLM-QA

Vision-Language Model은 이미지나 비디오와 텍스트를 함께 처리하는 모델이다. VLM-QA는 시각 입력과 질문을 받아 답을 생성하는 과제다.

### 벡터 데이터베이스 계층

설명문·이미지 임베딩과 구조화 메타데이터를 저장·색인하고 필터·어휘·벡터 검색과 순위 융합을 수행해 top-k를 반환하는 계층이다.

### 클립과 CLIP

- 클립(clip): 데이터셋이 배포한 mp4 파일 하나에 해당하는 연속 영상 구간. 저장·검색·qrels의 기본 단위.
- CLIP: 이미지와 텍스트를 공통 벡터 공간에 배치하는 대문자 모델명.

### 검색 문맥

DB의 top-k 검색 결과를 VLM 입력 형식으로 구성한 집합이다. DB 순위 목록과 VLM에 실제 전달된 픽셀·설명문 패킷을 구분해야 한다.

### 물질화(materialization)

영상에서 파생된 캡션이나 임베딩을 질의 때마다 계산하지 않고 미리 생성해 데이터베이스에 저장하는 것이다. 온라인 지연을 줄이지만 저장·갱신 비용이 생긴다.

## B. 평가 타당성 용어

### 데이터 누수

평가 시 알 수 없어야 할 정답 정보가 입력 특징·문서·조건에 들어가 실제 운용보다 성능을 높이는 현상이다.

### 평가 순환성

질의·필터·문서·정답을 같은 주석 계보에서 만들어 특정 방법의 우위가 데이터 구성상 보장되는 문제다.

### 비순환 작업 부하

predicate는 센서 기록, 검색 문서는 영상 픽셀 기반 모델, relevance는 사람 주석에서 독립적으로 생성한 작업 부하다.

### Tri-source protocol

원천 분리, 정답 재사용 금지, 자동 검증의 세 규칙을 가진 평가 데이터 생성 프로토콜이다. 프로토콜과 그 결과물인 데이터셋을 구분한다.

### qrels

Query relevance judgments. 각 질의에 어떤 문서·클립이 관련되는지 기록한 정답 표다.

### Strict relevance

의미상 관련되고 메타데이터 조건도 만족해야 정답이다. predicate를 필수 제약으로 해석한다.

### Semantic relevance

predicate 만족 여부와 별개로 의미상 관련된 클립을 정답으로 인정한다. 관심 단서 필터가 유용한 결과를 조기에 제거하는지 본다.

### Oracle

정답 정보를 이용한 이상적 상한 조건이다. 배치 가능한 방법이 아니라 파이프라인의 최대 가능성과 누수 효과를 측정하는 통제군이다.

### Restatement injection

정답 라벨의 정의 문장을 검색 문서에 덧붙여 document–answer circularity를 의도적으로 재현하는 통제 주입이다.

## C. 검색 계획·신호 용어

### Predicate / metadata filter

장소, 시각, 카메라, 센서 상태처럼 구조화 필드에 적용하는 조건식이다.

### Selectivity

전체 데이터 중 predicate를 통과하는 비율이다. 낮을수록 강한 필터지만 실제 ANN 난도는 선택도와 군집성 모두에 좌우된다.

### Hard constraint와 soft intent

- hard constraint: 반드시 지켜야 하는 계약. 위반 결과는 관련성이 있어도 오답이다.
- soft intent/cue: 검색을 돕는 선호 또는 단서. 위반 결과도 의미상 유용할 수 있다.

### Prefilter

predicate로 후보 집합을 먼저 줄이고 그 안에서 벡터 검색한다. 조건 준수에 강하지만 조기 누락 위험이 있다.

### Postfilter

전체 벡터 검색 후보를 먼저 얻고 predicate 불일치 결과를 제거한다. 의미 범위는 넓지만 top-k 부족이 생길 수 있다.

### Single-stage filtered ANN

ANN 탐색 과정 안에 predicate 판정을 통합하는 방식이다. 엔진별 graph traversal, bitmap, allow-list 구현이 다르다.

### BM25

문서 내 단어 빈도와 전체 코퍼스의 희귀도를 조합한 sparse 어휘 검색 함수다. 정확한 단어 일치에 강하지만 동의어·시각 의미에는 약하고 라벨 재진술 누수에 민감하다.

### Dense retrieval

질의와 문서를 임베딩한 뒤 벡터 유사도로 검색한다. 표현이 달라도 의미가 비슷한 문서를 찾을 수 있다.

### Cosine similarity와 L2 정규화

cosine similarity는 두 벡터의 방향 유사도를 측정한다. 벡터를 단위 길이로 L2 정규화하면 내적과 cosine 순위가 일치한다.

### RRF

Reciprocal Rank Fusion. 점수 대신 여러 검색기의 순위 역수를 합해 결과를 결합한다. 점수 캘리브레이션은 필요 없지만 약한 신호가 강한 신호를 희석할 수 있다.

### Lift

특정 신호가 있을 때 정답 확률이 전체 평균보다 얼마나 커지는지 나타낸다. 1을 기준으로 정의하기도 하고 차이로 정의하기도 하므로 보고서의 산식을 확인해야 한다. 본 연구 KG 보조 분석의 실질적 이득은 매우 작았다.

## D. 임베딩·색인 용어

### Embedding

텍스트·이미지 같은 객체를 의미 또는 시각 특성을 보존하는 고차원 숫자 벡터로 변환한 표현이다.

### Exact nearest-neighbor search / Flat

질의 벡터와 모든 벡터를 비교하는 정확 검색이다. recall 기준선이지만 데이터가 커질수록 지연이 선형 증가한다.

### ANN

Approximate Nearest Neighbor. 일부 후보만 탐색하여 매우 빠르게 이웃을 찾지만 정확 top-k를 놓칠 수 있다.

### HNSW

Hierarchical Navigable Small World. 계층 그래프를 따라 가까운 이웃을 탐색한다. 높은 recall과 낮은 지연을 제공하지만 그래프 저장·구축 비용이 크다.

- `M`: 노드당 연결 수. 크면 recall·메모리·구축비가 증가한다.
- `efConstruction`: 구축 중 후보 탐색 폭.
- `efSearch`: 검색 중 후보 탐색 폭. 크면 recall과 지연이 함께 증가한다.

### IVF-Flat

벡터를 `nlist`개 군집으로 나누고 질의와 가까운 `nprobe`개 군집의 원본 벡터만 검색한다. nprobe를 늘리면 recall과 지연이 증가한다.

### Product Quantization / IVF-PQ

벡터를 여러 부분공간으로 나누고 각 부분을 코드로 압축한다. 저장량을 크게 줄이지만 양자화 오차로 top-k fidelity가 낮아질 수 있다.

### Recall relative to Flat

Flat top-k를 기준 정답으로 보고 ANN이 그 이웃을 얼마나 재현하는지 측정한다. 사람 의미 qrels recall과 다른 지표다.

### Global / partial / local index

- global: 전체 코퍼스를 하나의 색인으로 관리.
- partial: 특정 자주 쓰는 predicate 부분집합만 별도 색인.
- local: 장소·센서·시간 파티션별 색인이라는 더 넓은 운영 개념.

### Hot / cold path

질의 빈도와 데이터 최신성에 따라 빠른 별도 색인과 저비용 공용·정확 검색 경로를 나누는 정책이다.

### Fallback

ANN 탐색이 비효율적인 강한 필터에서 엔진이 전수 검색이나 다른 실행 경로로 전환하는 것이다. recall은 회복하지만 지연이 증가할 수 있다.

### Build amortization / break-even

부분 색인 구축 비용을 반복 질의의 지연 절감으로 회수하는 개념이다. 다음 갱신까지 예상 질의 수가 손익분기 `N*`를 넘어야 경제적이다.

## E. 통계·평가 지표 용어

### nDCG@k

관련 결과가 상위에 얼마나 잘 배치됐는지 측정하고 이상적 순위로 정규화한 지표다. 0–1 범위다.

### Recall@k

전체 관련 결과 중 top-k에 회수된 비율이다. 관련 결과가 매우 많으면 top-k 제한 때문에 최대값이 작을 수 있으므로 정의를 확인한다.

### MRR

첫 관련 결과의 순위 역수 평균이다. 첫 성공의 빠르기를 강조한다.

### p50 / p95

지연 분포의 50번째·95번째 백분위수다. p95는 꼬리 지연과 SLA에 중요하다.

### Effect size Δ

처리군과 기준선의 성능 차이다. 유의성 외에 실제 크기를 보여준다.

### Confidence interval

불확실성을 구간으로 나타낸다. 차이의 CI가 0을 포함하면 현재 데이터로 효과 방향을 확립하지 못한 것이다. 이는 두 방법이 완전히 같다는 증명이 아니다.

### Bootstrap

관측치를 반복 재표집해 통계량의 표본 분포를 근사하는 방법이다. 검색 질의의 비정규 분포에 유용하다.

### Cluster bootstrap

서로 의존하는 질의를 개별로 흩뜨리지 않고 조건–의미 쌍 같은 군집 단위로 재표집한다.

### Wilcoxon signed-rank test

대응 관측의 차이를 순위로 검정하는 비모수 방법이다.

### Spearman rho

두 변수의 단조 관계를 순위로 측정하는 상관계수다. 인과를 뜻하지 않는다.

### Cramér's V

두 범주형 변수의 결합 강도다. 본 연구에서는 predicate와 semantic relevance의 결합을 층화한다.

### Type I error와 multiple comparisons

실제 효과가 없는데 있다고 판단하는 오류가 1종 오류다. 비교 횟수가 늘면 적어도 하나의 거짓 양성이 나올 확률이 증가한다.

### Holm correction

주요 가설 집합의 family-wise error를 제어하는 단계적 보정이다. 보수적 확증 비교에 사용한다.

### Benjamini–Hochberg FDR

기각한 가설 중 거짓 발견의 기대 비율을 제어한다. 많은 탐색적 비교에 사용한다.

### Statistical significance와 practical significance

통계적 유의성은 우연 변동만으로 관측되기 어려움을 뜻하고, 실용적 유의성은 효과 크기가 비용·SLA 관점에서 가치 있음을 뜻한다. 둘은 별개다.

### Power와 미확립

표본이 작거나 중개 효과가 약하면 실제 효과가 있어도 검정이 잡지 못한다. 이 경우 “효과가 없다”가 아니라 “현재 표본에서 확립되지 않았다”고 쓴다.

### Paired comparison

같은 질의·코퍼스에서 방법만 바꿔 차이를 비교하는 설계다. 질의 난이도 변동을 제거한다.

### Pareto frontier

품질·지연·저장·구축 비용 중 어느 하나를 개선하려면 다른 축을 희생해야 하는 비지배 구성들의 경계다.

## F. 인과·전파 용어

### Mediator

원인과 최종 결과 사이에서 효과를 전달하는 중개 변수다. 색인 선택이 답변을 바꾸려면 먼저 top-k 또는 정답 증거 적중률을 바꿔야 한다.

### Evidence retrieval propagation

검색 개선이 `top-k 변화 → 관련 증거 적중 → VLM 인식 → 답변 변화`로 이어지는 과정이다.

### Perception wall

정답 검색 문맥이 들어와도 VLM이 작은 객체·시점·시간 관계를 인식하지 못해 답변 향상이 막히는 경계다.

### Answer bias

모델이 증거와 무관하게 특정 선택지·문구·yes/no 방향을 선호하는 현상이다. 검색 효과처럼 보일 수 있어 통제가 필요하다.

### Oracle upper bound

대상 설명문·정답 프레임을 직접 제공했을 때의 답변 상한이다. 이 상한이 낮으면 검색보다 지각·질문 설계가 병목이다.
