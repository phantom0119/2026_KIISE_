# 2. 관련 연구와 연구 공백

## 2.1 데이터 누수와 평가 순환성

데이터 누수는 평가 대상이 맞혀야 할 목표 정보가 입력 특징이나 평가 자료에 다시 들어가 실제 운용보다 높은 성능을 만드는 현상이다. 평가 순환성은 도구나 모델을 만드는 데 사용한 자료와 평가 기준의 생성 경로가 겹쳐 상대 비교를 왜곡하는 구조적 문제다.

본 연구는 이 개념을 벡터 데이터베이스 작업 부하로 확장한다. 검색 문서·질의·필터·정답 집합이 같은 주석 계보를 공유하면 검색기의 장면 이해와 평가 자료가 제공한 힌트를 분리할 수 없다. 해결 방법은 단순 텍스트 중복 제거가 아니라 생성 원천의 분리와 재사용 금지, 자동 감사다.

## 2.2 멀티모달·비디오 RAG

RAG는 외부 자료를 먼저 검색하여 생성 모델의 입력에 제공한다. VideoRAG는 이를 영상 코퍼스로 확장한다. CLIP 계열 모델은 이미지와 텍스트를 공통 임베딩 공간에 배치해 자연어–이미지 검색을 가능하게 한다.

기존 연구의 주요 관심은 검색 결과를 생성 모델에 잘 전달하거나 표현 모델의 정확도를 높이는 것이다. 본 연구는 검색용 데이터를 데이터베이스에 물질화된 실체로 보고, 표현의 저장량·색인 크기·구축 시간·질의 지연까지 함께 측정한다.

## 2.3 Filtered Vector Search와 벡터 데이터베이스

VBASE, ACORN, pgvector, Milvus, Weaviate 등은 구조화 조건과 벡터 유사도 검색을 결합한다. 핵심은 필터를 검색 전, 검색 후, 또는 ANN 탐색 중에 적용하는 실행 계획과 물리 색인이다.

기존 벤치마크는 선택도만 맞춘 무작위 마스크를 자주 사용한다. 그러나 실제 장소·시간 조건은 임베딩 공간에서 군집될 수 있으므로 같은 선택도라도 그래프 또는 군집 탐색을 훨씬 어렵게 만든다. 본 연구는 실측 조건과 동일 선택도의 무작위 대조군을 짝지어 이 차이를 분리한다.

## 2.4 도시 감시 영상-언어 이해

VRU-Accident, UCA/UCF-Crime, MEVA, 다각도 CCTV, Spatialyze 계열 연구는 사고·이상행동·시공간 조건을 영상 질의 또는 VQA와 연결한다. 이들은 도메인 타당성과 질문·답변 과제를 제공하지만, 데이터 원천 분리와 데이터베이스 물리 설계의 통합 비교가 주목적은 아니다.

## 2.5 논문이 메우는 공백

기존 연구는 다음 축을 개별적으로 다뤘다.

- 영상 검색과 VLM 답변
- 필터 결합 벡터 검색
- 임베딩과 멀티모달 표현
- ANN 색인 성능
- 데이터 누수와 평가 타당성

본 연구는 이들을 `원천 분리 → 검색용 데이터 저장 → 조건 계획 → 신호 결합 → 물리 색인·배포 → 최종 답변`이라는 하나의 종단 파이프라인에서 연결한다. 핵심 차별점은 새로운 검색 모델 하나를 제안하는 것이 아니라, **어떤 데이터베이스 설계를 어떤 평가 계약과 자원 조건에서 선택해야 하는지**를 실증적으로 제시한다는 점이다.

## 선행 연구를 읽을 때의 질문

- 필터와 정답이 같은 주석에서 나오지 않았는가?
- 검색 문서가 정답 문구를 재진술하지 않았는가?
- 무작위 선택도 실험이 실제 시공간 군집을 대변하는가?
- 정확도만 보고 저장·구축·지연 비용을 누락하지 않았는가?
- 검색 지표 상승을 답변 정확도 상승으로 바로 해석하지 않았는가?
