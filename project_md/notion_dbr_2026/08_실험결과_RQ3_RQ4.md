# 5.2.3–5.2.4 실험 결과 — RQ3과 RQ4

## RQ3. 검색 계획과 조건–의미 결합도

### 전체 전략 결과

| 전략 | strict nDCG@10 | semantic nDCG@10 | 핵심 해석 |
|---|---:|---:|---|
| 메타데이터 단독 | 0.218 | 0.217 | 검색기보다 조건–정답 물리 결합도를 반영 |
| BM25 | 0.017 | 0.050 | 비순환 문서에서 어휘 신호가 약함 |
| 벡터 단독 | 0.059 | 0.170 | semantic 목적의 dense 기준선 |
| 검색 후 조건 적용 | 0.152 | 0.150 | top-200 후 필터, 소형 코퍼스에서 후보 포화 |
| 검색 전 조건 적용 | 0.157 | 0.154 | strict 향상, semantic에서는 벡터 단독 아래 |
| 혼합 검색 | 0.135 | 0.133 | 약한 BM25가 벡터 순위를 희석 |

### 필수 제약과 관심 단서

strict에서는 사전 필터 `0.157`이 벡터 단독 `0.059`보다 `+0.0983`, 95% CI `[+0.068,+0.133]` 높다. 그러나 정답 정의 자체가 predicate 만족을 요구하므로 조건을 먼저 적용할 때 유리한 것은 상당 부분 자명하다.

semantic에서는 벡터 단독 `0.170`이 가장 높고 사전 필터 `0.154`, 사후 필터 `0.150`, 혼합 검색 `0.133` 순이다. 사전 필터–벡터 단독의 통합 차이 `−0.0158`, CI `[−0.047,+0.015]`는 0을 포함한다. “필터가 해롭다”가 아니라 전체 평균에서 뚜렷한 차이가 확립되지 않았다는 뜻이다.

### 질의 표본에 따른 자기 교정

| 질의 표본 | 사전 필터−벡터 semantic Δ [95% CI] |
|---|---:|
| 초기 수작업 32질의 | −0.0745 [−0.136,−0.014] |
| 기계적 확장 53질의 | +0.0197 [−0.008,+0.050] |
| 통합 85질의 | −0.0158 [−0.047,+0.015] |

초기 표본은 초저결합 손해 영역을 과대표집했다. 사전 규칙으로 조건–의미 교차곱을 확장하자 강한 음의 효과가 사라졌다. 이것은 질의 선택 자체가 연구 결론을 만들 수 있음을 보여주는 중요한 자기 교정 사례다.

### 결합도 층화

| 층 | semantic Δ | pair-cluster 95% CI | 해석 |
|---|---:|---:|---|
| 저결합 `V<0.3` | −0.0357 | [−0.094,+0.010] | 손실 경향, 군집 CI는 0 포함 |
| 고결합 `V≥0.3` | +0.1335 | [+0.078,+0.356] | 사전 필터의 추가 이득 |

질의 단위로는 저결합 75개, 고결합 10개다. 표의 군집 분석 단위는 각각 23개와 2개의 조건–의미 쌍이므로 `질의 수`와 `쌍 수`를 혼용하면 안 된다. 고결합 쌍이 2개뿐이므로 외적 일반화에는 제한이 있다.

### UCA 외부 대조

| 가설 | AI Hub | UCA |
|---|---:|---:|
| strict의 사전 필터 효과 | +0.0983 | +0.1501 |
| 저결합 semantic 효과 | −0.0357 | −0.0485 |
| 사전 필터가 불리한 질의 | 30.6%(26/85) | 52.7%(68/129) |
| 고결합 추가 이득 | +0.1335 | −0.0558 |

필수 제약의 이득과 관심 단서의 손실 방향은 재현됐지만, UCA에는 독립 센서 채널이 없고 고결합 질의가 매우 적어 고결합 이득은 재현되지 않았다.

### RQ3 운영 규칙

- 필수 제약: 검색 전 조건 적용을 기본으로 고려한다.
- 저결합 관심 단서: 벡터 단독을 기본으로 두고 사전 필터의 누락을 검증한다.
- 고결합 관심 단서: 사전 필터의 품질·지연 동시 이득 가능성을 시험한다.
- predicate 오류나 누락이 크면 strict 계약 자체의 타당성을 재검토한다.

## RQ4. 검색 신호와 순위 융합

### 네 신호의 비교

- 메타데이터 단독: strict `0.218`, semantic `0.217`
- BM25: strict `0.017`, semantic `0.050`
- 벡터 단독: strict `0.059`, semantic `0.170`
- 사전 필터 후보에서 BM25–벡터 RRF: semantic `0.133`, 같은 후보의 벡터 단독 `0.154`

메타데이터 단독의 높은 점수는 ID 순위화가 우수하다는 뜻이 아니라 조건과 정답의 결합이 강하다는 뜻이다. 라벨 재진술을 제거한 뒤 BM25는 약했고, 이를 RRF로 섞자 벡터 단독보다 성능이 낮아졌다.

### RRF의 핵심 원리

서로 다른 검색기의 점수 척도는 직접 더하기 어렵다. RRF는 각 결과의 순위만 이용한다.

$$
RRF(d) = \sum_{r\in R}\frac{1}{k + rank_r(d)}
$$

논문은 상수 `k=60`을 사용한다. RRF는 신호를 자동으로 개선하는 마법이 아니며, 약한 입력 순위도 일정한 투표권을 갖기 때문에 좋은 순위를 희석할 수 있다.

### 지식그래프 재조합 보조 실험

센서 조건과 설명문 개체로 만든 지식그래프에서 특정 개체가 정답일 확률을 높이는 Lift 중앙값은 `0.002`였다. KG 순위의 strict nDCG@10 `0.176`은 메타데이터 단독 `0.218`보다 낮았다. 세 원천 규칙 때문에 새 정답 채널을 KG에 넣을 수 없고, 캡션 개체와 센서 조건을 재조합한 것만으로는 새로운 판별 신호가 되지 않았다.

### RQ4 결론

비순환 평가에서 BM25, BM25–벡터 RRF, 현재 KG 재조합은 독립 이득을 보이지 않았다. 이는 모든 hybrid retrieval이 나쁘다는 일반 명제가 아니다. **융합 전에 각 신호의 독립 품질과 상보성을 검증해야 하며, 약한 신호를 무조건 섞지 말라**는 결과다.
