# 760 — 본 연구 실험 체계 Flow (배경→문제→설정→방법→결과), 2026-07-14

실측 검증(740 감사·720/700 결과·750 baseline) 기반. 4단계 서사로 전체를 정리.

## 큰 그림 (한 줄 flow)

**[기존연구 조사 → 순환성 발견] → [붕괴로 정량 확인] → [비순환 tri-source 프로토콜 제안] → [522 중심 데이터셋 + 표준 RAG 워크로드 구축] → [저장·색인·필터·배포·엔진을 변수화한 설계공간 파이프라인] → [구조 선택 지침 + 외적타당성(MEVA·MIRIS·UCA)]**

---

## ① 연구 배경 → 문제 정의

**배경.** 도시 교통·감시 환경은 영상 프레임 + 사건 텍스트 + 센서(신호위상·차량·보행량) 메타데이터를 동시 생산한다. 관제 질의는 "오전에 자전거 2대 이상 장면"처럼 **자연어 의미 조건 + 메타데이터 조건**이 결합된 형태다. VLM이 신뢰할 답을 내려면 **DB가 먼저 올바른 증거를 저장·색인·검색**해야 한다 → 데이터 관리 문제(RQ-S 구조 / RQ-ALC 정확도·지연·비용 / RQ-M 다중모달).

**문제 발견 (기존 연구·데이터셋 조사 중).** 라벨 풍부한 공개 데이터셋으로 검색 워크로드를 구성하면 **질의 템플릿·메타데이터 필터·정답(qrels)·색인 문서가 모두 같은 주석 라벨에서 파생**되기 쉽다 → **순환성(circularity)**: (C1) 필터⊆정답이면 prefilter 우위가 **구성상 보장**, (C2) 라벨 재진술 문서면 어휘 매칭만으로 **완벽 지표**.

**정량 확인 (문제가 실재함).** 두 순환 워크로드를 수리 전후로 재측정 → **완벽 지표가 붕괴**:
- VRU: B4 nDCG 0.97→0.32, 지능형 CCTV: BM25 0.96→0.11(라벨 문자열 매칭 폭로).
- 수리 후 semantic에서 질의별 (B4−B2) 부호에 **음수 등장**(v1에선 구조적으로 불가능) = "prefilter 우위 보장"이 실제로 깨진 직접 증거.

**설계 목적 (새 통찰/가이드).** ⇒ "모델이 아니라 **구조와, 구조 평가의 타당성**"을 다뤄야 한다. **비순환 워크로드 프로토콜**을 첫 기여로 두고, 그 위에서 저장·색인·검색 구조 선택 지침을 도출하는 것이 연구 목표.

## ② 실험 설정 (데이터셋 + 워크로드 flow)

**데이터셋 (실측 확인, 740).**

| 역할 | 데이터셋 | 용도 |
|---|---|---|
| **메인 헤드라인** | AI-Hub 522 교차로 CCTV(63교차로·32,880클립) | 비순환 tri-source(A6 6/6 PASS) |
| 색인 코퍼스 | sinnaedoro 132K + 522-visual 143K (CLIP 512d) | filtered-ANN·색인 3축·pgvector |
| 외적타당성 | **MEVA**(검색)·**MIRIS**(색인/배포)·**UCA**(검색) | 국제·타도메인 재현 |
| 붕괴 데모 | VRU·지능형 CCTV | 순환→수리 붕괴 |
| 답변 계층 | 다각도 CCTV | 다시점 답변 선택 |

**워크로드 flow (비순환 tri-source):**
```
raw(프레임 + CVAT 주석 + 센서 CSV)
  → facet 분리:  PREDICATE=센서기록 ⟂ RELEVANCE=사람주석 ⟂ DOCUMENT=VLM캡션(픽셀만)
  → canonical(clips/documents/metadata/queries + strict·semantic 이중 qrels)
  → A6 기계감사(세 채널 소스 분리·정답 재진술 0·희소 정답·prefilter 비보장성)
  → 임베딩:  문서/질의=bge-m3(1024d) · 프레임=CLIP ViT-B/32(512d)
  → 검색/색인 (표준 RAG: embed + ANN + 메타데이터 필터 + 고정 VLM)
```
- 핵심 축: **이중 정답**(strict=필터∧의미 / semantic=의미만) + **결합도 스펙트럼**(predicate-relevance V).
- 검색 파이프라인은 **보편적 RAG 표준**(750: 문서임베딩+질의임베딩+ANN+분리 메타필터; 벡터DB 7종·프레임워크 3종 확인).

## ④ 실험 결과 → 결론 (새 통찰)

**핵심 발견:**
1. **순환성 = 완벽 지표는 경고 신호** — 3중 붕괴 재현으로 실증(§4).
2. **prefilter 가치 = 제약 경성 × 결합도** — 하드 제약 strict **+0.098 [0.068,0.133] 확증**; soft는 결합도 따라 부호(저결합 −0.099, 자연결합 +0.134; 쌍 군집 CI 0 포함=탐색적)(§6). **MEVA 재현: strict +0.093 [0.075,0.113] CI 0 배제**.
3. **filtered-ANN 재현율 편향** — 실 predicate가 공유색인 postfilter를 **동일선택도 무작위 대비 최대 +0.63 과대평가**; pgvector 재현; 전용엔진(Milvus·Weaviate) 다층 완화로 대부분 흡수(§7.1·7.2).
4. **저장 단위는 데이터셋/인코더 정합 의존** — 522=clip-caption Pareto, MEVA=frame-vector 지배; multi·dual 무익(§7.5).
5. **partial/local index가 선택적 predicate에서 global을 지배** — global은 recall(공간 predicate에서 relaxed조차 0.49 붕괴) 또는 지연(시간 predicate 8.1ms) 중 하나 희생, partial은 recall 0.99·지연 0.4ms 동시 유지; hot/cold N* 정책; **MIRIS 교통 재현**(§7.5).
6. **색인 3축** — 143K 실측서 HNSW 지배(≈300× 지연이득), PQ는 저장극한(22–35× 압축/recall↓)(§7.3).
7. **색인→답변 전파는 세 경계**(스케일·생성기 능력·과제 비오염)의 좁은 교집합서만 관측(§8).

**종합 통찰(결론).** 대량 멀티모달 감시 DB에서 **검색·색인 구조 선택은 (i) 워크로드 타당성(비순환)을 먼저 감사한 위에서, (ii) 결합도 스펙트럼 위에서 평가돼야 하며, (iii) 저장→색인→필터→배포 설계공간에는 데이터셋-의존적 최적점이 있다.** 이 지침은 국내 522·해외 MEVA·SIGMOD MIRIS·영어 UCA에서 교차 재현되어 외적타당성을 확보. 방법론(소스 분리·기계 감사·이중 정답·결합도 보고·사전등록 게이트)은 도메인이 달라도 이식 가능.

### 단계 간 인과 (왜 이 순서인가)
① 순환성을 **발견·정량화**했기에 → ② **비순환 워크로드**부터 구축해야 하고 → ③ 그 타당한 워크로드 위에서만 **구조 선택지 비교**가 의미를 가지며 → ④ 그 비교에서 **결합도·데이터셋-의존적 설계 지침**이라는 통찰이 나온다. 즉 "타당성 없는 벤치마크는 구조 비교를 오염시킨다"가 전 단계를 관통하는 축.
