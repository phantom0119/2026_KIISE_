# 멀티모달 영상 RAG 파이프라인을 위한 비순환 평가와 데이터베이스 계층의 검색 품질-비용 실증 연구

## An Empirical Study of Non-circular Evaluation and Database-Layer Retrieval Quality-Cost Trade-offs for Multimodal Video RAG Pipelines

## 요 약

대규모 영상 RAG 시스템은 벡터 데이터베이스의 데이터 저장 형태, 색인, 필터 조건 설계에 따라 검색 품질과 자원 비용이 결정되며 서로 상충 관계에 있다. 이를 왜곡 없이 비교하려면 데이터베이스 계층의 검색 품질과 비용을 같은 평가 절차에서 측정하고, 검색 결과의 답변 전파는 별도 단계에서 검증해야 한다. 또한 검색 작업 부하를 구성할 때 정답 주석이 검색 문서나 메타데이터 조건에 다시 유입되는 평가 순환성을 차단해야 한다. 이에 본 연구는 메타데이터, 영상 설명문, 사람 주석의 생성 경로를 분리한 비순환 평가 체계를 구축하고, 벡터 데이터베이스 설계 축의 품질-비용 상충 관계와 VLM 답변 효과를 단계적으로 평가하였다. 실험 결과, 정답 주입 시 nDCG@10이 0.181에서 1.000까지 부풀려지는 왜곡을 규명하였다. 또한 다중 이미지 구성은 설명문 구성보다 float32 벡터 저장량이 2.8배, 검색 지연이 3배로 증가했으며, 실측 군집 조건과 연관된 근사 색인의 재현율 손실은 조건별 부분 색인에서 동일 조건 정확 검색 대비 0.981~0.995로 완화되었다. 반면 검색 품질 개선이 VLM 답변 품질로 자동 전파되지는 않아, 증거 회수·모델 인식·과제 편향을 단계별로 확인해야 했다. 후속 통제 분석에서 과제 범주를 열거하지 않은 프롬프트는 의미론적 nDCG@10을 0.1700에서 0.0855로 낮추어, 직접 정답 재사용 차단이 프롬프트 비의존성을 뜻하지 않음도 확인하였다. 결과적으로 본 연구는 직접 정답 정보의 재사용을 차단한 검색 작업 부하와, 그 프롬프트 조건부 적용 범위를 포함하여 제한된 자원에서 품질-비용 절충안을 선택하기 위한 데이터베이스 계층 물리 설계 지침을 제시한다.

**주제어:** 도시 교통 감시, 멀티모달, 벡터 데이터베이스, 시각 언어 모델, 검색 증강 생성

## Abstract

In large-scale video RAG systems, retrieval quality and resource cost depend on how data is represented, indexed, and filtered in the vector database. We therefore evaluate database-layer retrieval quality and cost under a common protocol and test answer propagation as a separate downstream stage. We also prevent evaluation circularity in which relevance annotations re-enter retrieval documents or metadata predicates. To this end, we construct a workload with separated provenance for metadata, video descriptions, and human relevance annotations, and evaluate quality-cost trade-offs across vector-database design choices. Injecting ground-truth information inflates nDCG@10 from 0.181 to 1.000. Compared with caption vectors, a multi-frame configuration uses 2.8× the float32 vector payload and incurs 3.0× the retrieval latency. Recall losses associated with naturally clustered predicates are mitigated by predicate-specific partial indexes, which achieve 0.981–0.995 recall relative to exact search under the same predicates. Retrieval gains, however, do not automatically propagate to final VLM answer quality, requiring separate checks of evidence retrieval, model perception, and task bias. In a follow-up control, a prompt that did not enumerate task categories reduced semantic nDCG@10 from 0.1700 to 0.0855, showing that blocking direct ground-truth reuse does not establish prompt independence. Overall, this study provides a retrieval workload that blocks direct ground-truth reuse and database-layer physical-design guidance whose scope explicitly includes this prompt dependence.

**Keywords:** Urban Traffic Surveillance, Multimodal, Vector Database, Vision-Language Model, Retrieval-Augmented Generation

# 1. 서 론

대규모 영상 데이터 집합에서 필요한 정보를 효율적으로 탐색하기 위해 영상의 시각 정보와 자연어 질의를 결합하는 멀티모달 영상 검색 증강 생성(Retrieval-Augmented Generation, RAG) 파이프라인이 현대 검색 시스템의 핵심 구조로 자리 잡았다. 이 파이프라인은 데이터베이스에서 사용자 질의와 관련된 소수의 핵심 영상 구간을 먼저 검색하고, 이를 시각 언어 모델(Vision-Language Model, VLM)에 참고 정보로 제공하여 생성 답변의 정확도를 높인다. 그러나 영상을 각 질의마다 VLM에 직접 입력하는 방식은 문맥 길이 상한 초과와 GPU 연산 비용 폭증을 유발한다[1]. 따라서 영상을 어떠한 형태로 적재하고 어떠한 색인과 필터 검색 계획을 적용하는지에 따라 시스템의 검색 품질과 물리적 자원 비용이 결정되므로, '데이터베이스 계층'의 물리 설계 최적화가 핵심 병목으로 부각된다[2].
   데이터 저장 형태와 색인·검색 방식은 여러 분야에서 파편화되어 연구되어 왔다. VideoRAG[1]는 질의 관련 영상과 대표 이미지를 검색해 생성 모델에 제공하고, CLIP[3]과 같은 시각·언어 임베딩 모델은 영상 이미지와 자연어 질의 간의 벡터 유사도 검색에 사용된다. VBASE[4]와 ACORN[5]은 벡터 데이터베이스 시스템에서 구조화 조건과 벡터 유사도 검색을 결합하되, 주로 검색 실행 경로와 물리 색인의 성능에 초점을 맞추었다. 그러나 이러한 선행 연구들만으로는 검색용 데이터, 필터 결합 계획, 물리 색인과 비용을 하나의 평가 절차에서 비교하고 검색 결과의 답변 효과를 별도 단계에서 확인하기 어렵다.
   더 근본적인 한계는 검색 작업 부하를 만드는 과정의 순환성이다. 기존 영상 벤치마크[6,7]를 검색 평가로 변환하면서 질의, 메타데이터 조건, 검색 문서와 검색 정답 집합을 같은 사람 주석에서 파생하면 '평가 순환성(Evaluation Circularity)[8]'과 '데이터 누수(Data Leakage)[9]'의 위험이 커진다. 본 연구는 RAG 파이프라인에서 이러한 평가 순환성을 통제 주입으로 모사했다. 그 결과, 정답 라벨을 검색 문서에 재진술하기만 해도 nDCG@10[10]이 0.181에서 0.854로 상승함을 보였다. 이는 실제 장면 이해가 아니라 주석 재사용이 성능으로 오인될 수 있음을 보여준다.
   본 연구는 주 평가 작업 부하에서 메타데이터, 영상 설명문, 사람 주석의 생성 경로를 분리하고, 정답 필드와 직접 라벨 토큰의 재사용을 자동 검사한다. 여기서 비순환성은 직접적인 정답 정보 재사용을 차단했다는 뜻이며, 동일 장면에서 파생된 채널의 통계적 독립이나 캡션 프롬프트의 과제 중립성을 뜻하지 않는다. 그리고 정답 기반 조건과 라벨 재진술을 의도적으로 주입한 통제 실험으로 순환성이 검색 점수를 부풀리는 정도를 정량화한다. 또한 저장 방식, 필터 조건, 검색 신호, 물리 색인과 배포의 비교 항목을 같은 평가 원칙과 공통 측정 절차 아래 단계적으로 측정한다.
   실험 결과, 직접 정답 정보 재사용을 차단한 작업 부하에서는 주입 전보다 낮고 현실적인 검색 점수가 관찰되었고, 통제 주입은 정답 정보 재사용의 왜곡 효과를 확인해 주었다. 다중 이미지 방식은 의미론적 검색 품질(nDCG@10)의 점 추정치를 0.181에서 0.352로 높였지만, float32 벡터 저장량(24.6MB→68.4MB)과 검색 지연(1.15ms→3.65ms)이 증가했다. 또한 전역 근사 색인에서 실측 시공간 군집 조건과 연관된 재현율 손실(최대 0.627)을 관찰했으며, 조건별 부분 색인은 동일 조건 정확 검색 대비 재현율 0.9812~0.9952를 달성했다. 단, 데이터베이스 계층의 검색 성능 개선이 최종 VLM 답변 품질로 자동 전파되지는 않았다.
   본 연구의 공헌은 다음과 같다.
   • 본 연구는 데이터 원천의 생성 경로를 분리하고 직접적인 정답 라벨 누출을 자동 검사하는 평가 체계를 수립하여 검색 성능 지표의 부풀림 현상을 정량적으로 진단하며, 후속 프롬프트 대조로 이 체계의 적용 범위를 명시한다.
   • 본 연구는 저장 방식, 필터 조건, 검색 신호, 물리 색인, 배포 비용의 설계 축을 동일한 비순환 평가 원칙과 공통 측정 절차 아래 다차원적으로 비교하여 검색 성능과 자원 비용을 정밀 측정한다.
   • 본 연구는 검색 개선이 생성 모델의 답변 품질로 전파되기 위한 조건을 증거 회수, VLM 인식, 과제 편향의 단계로 나누어 진단하고, 전파가 자동적이지 않음을 보임으로써 단계별 검증 절차를 포함한 설계 지침을 도출한다.
   본 논문의 구성은 다음과 같다. 2장은 관련 연구를 정리하고, 3장은 데이터베이스 계층의 비순환 조건부 설계 선택 문제를 정의한다. 4장은 비순환 평가 작업 부하와 데이터베이스 계층 설계 공간을 포함한 방법론을 설명한다. 5장은 여섯 연구 질문에 따라 실험 결과를 분석하고, 6장은 결론과 향후 연구를 제시한다.

# 2. 관련 연구

   데이터 누수는 목표 정보를 특징이나 평가 자료에 다시 사용하여 실제 운용보다 높은 성능을 만든다[9]. 그리고 같은 자료에서 학습과 평가 기준을 구성하는 순환성은 도구 간 비교를 왜곡한다[8]. 검색 문서·질의·검색 정답 집합이 같은 주석에서 파생되면 검색기의 장면 이해와 평가 자료가 제공한 단서를 분리하기 어렵다. 본 연구는 이 원리를 벡터 데이터베이스 검색 작업 부하로 확장하여 센서 기록·영상 설명문·사람 주석을 분리하고, 정답 기반 조건과 라벨 재진술을 각각 주입한 통제 실험을 바탕으로 정답 정보의 재사용이 검색 점수를 부풀리는지 확인한다.
   RAG는 사용자 질의에 부합하는 외부 지식을 먼저 검색하고, 이를 생성 모델에 참고 정보로 제공하여 답변의 신뢰성을 높이는 기술이다. VideoRAG는 이를 영상 코퍼스로 확장하고, CLIP은 이미지와 텍스트를 공통 벡터 공간에 배치해 이미지 검색으로 확장한다. 본 연구는 이러한 검색 대상 데이터를 단순한 생성 모델용 입력으로만 두지 않고, 데이터베이스에 물리적으로 저장되어 벤치마킹되는 실체적 대상으로 취급한다. 이에 따라 영상 설명문, 대표 이미지, 다중 이미지, 이미지·설명문 결합 벡터와 이중 색인 구조를 동일한 질의와 정답 기준에서 검색 품질·지연 시간·저장 용량으로 비교한다. 각 검색용 데이터가 최종 VLM 답변에 미치는 영향은 관련 설명문과 카메라 시점을 대상으로 한 별도의 답변 실험에서 검증한다.
   메타데이터 조건은 근사 최근접 이웃(ANN) 검색 전·후 또는 탐색 과정에 적용할 수 있으며, 그 성능은 조건 통과 비율뿐 아니라 통과 벡터의 공간 분포와 색인의 탐색 구조에 좌우된다[11]. VBASE[4]는 관계형 질의처리와 벡터 검색을 연결하고, 반복 탐색은 pgvector[12], 그래프 탐색과 조건 처리는 Milvus[13]와 ACORN[5]에서 다뤄졌다. 본 연구는 메타데이터 조건을 필수 제약과 관심 단서로 구분해 평가한다. 같은 수의 벡터를 통과시키는 무작위 조건과 실측 장소·시간 조건을 짝지어 비교하고, 두 조건의 차이가 벡터 검색 라이브러리와 실제 벡터 데이터베이스에서도 나타나는지 확인한다.
   VRU-Accident[6]와 UCA[14]는 사고·이상행동 영상을 자연어 질의 및 답변과 연결한다. Spatialyze[15]는 시공간 조건을 이용해 영상 분석 대상을 축소한다. 이들 연구는 도시 감시 장면을 언어로 질의하거나 메타데이터 조건으로 처리 범위를 줄인다는 점에서 본 연구와 결을 같이한다. 다만 이들의 초점은 영상 이해 모델, 검색 파이프라인, 답변 정확도에 있다. 반면 본 연구는 검색용 데이터의 저장 방식, 메타데이터(필터) 조건 적용, 검색 신호, 물리 색인, 배포 비용을 비순환 평가 아래 설계 축별로 비교한다. 또한 검색 단계의 차이가 최종 답변으로 전파되는 조건을 별도로 검증한다.
   기존 연구는 영상 질의 처리, 필터 결합 벡터 검색, 영상 언어 이해를 각각 발전시켰다. 그러나 평가 자료의 생성 경로부터 저장 방식, 메타데이터 조건, 검색 신호, 물리 색인, 배포 비용과 최종 답변의 효과까지 하나의 절차에서 함께 비교하지는 않았다. 본 연구는 비순환 작업 부하를 먼저 확립하고, 각 설계 선택의 검색 품질과 비용을 비교한 뒤 검색 결과가 답변으로 전파되는 조건을 검증하여 이 공백을 메운다.

# 3. 문제 정의

   본 연구가 다루는 문제는 두 가지다. 첫째, 도시 감시 영상 검색 평가에서 질의, 메타데이터 조건, 검색용 문서 및 검색 정답 집합을 동일한 사람 주석에서 함께 파생하면 '평가 순환성'으로 인해 검색 품질 지표가 왜곡될 수 있다. 단일 출처라는 사실만으로 누수가 필연적인 것은 아니지만, 정답 라벨이나 그 재진술이 메타데이터 조건·검색 문서로 되돌아오면 검색기가 영상의 실제 장면을 이해하지 못하더라도 점수가 부풀려져 데이터베이스 계층의 비교를 방해한다[8,9].
   둘째, 순환성을 차단하더라도 검색용 데이터·검색 계획·검색 신호·물리 색인·배포의 최적 구성은 하나로 고정되지 않고, 무엇을 관련 영상으로 인정할지(정답 기준)와 서비스 비용 제약에 따라 달라진다. 따라서 본 연구의 문제는 하나의 검색 점수를 최대화하는 것이 아니라, 비순환 평가 아래에서 서비스가 요구하는 재현율·지연 시간·저장량·구축 비용 한도를 만족하는 후보 중 사용 목적에 맞는 정답 기준의 검색 품질이 가장 높은 데이터베이스 계층 구성을 선택하는 것이다.
   이 문제를 정의하려면 데이터베이스 계층의 입력과 출력, 그리고 정답 기준을 밝혀야 한다. 데이터베이스 계층은 원본 영상과 센서 메타데이터, 미리 생성한 영상 설명문·벡터를 저장하고, 자연어 의미 조건과 메타데이터 조건, 반환 수를 입력받아 상위 영상 클립을 반환한다. 각 결과에는 식별자, 원본 위치, 촬영 시간, 검색 점수와 메타데이터가 포함된다. 동일한 메타데이터 조건도 사용자 의도에 따라 반드시 지켜야 하는 필수 제약이거나 검색 대상을 설명하는 관심 단서일 수 있다. 필수 제약일 때는 의미 조건과 메타데이터 조건을 모두 만족하는 항목을 ‘엄격한 정답’으로 정의하여 조건 준수 여부를 평가하고, 관심 단서일 때는 의미 조건을 만족하는 모든 항목을 ‘의미론적 정답’으로 정의하여 조건 적용으로 관련 영상이 제외되는지를 평가한다. 이 두 가지의 ‘정답 기준’은 이후 검색 계획을 해석하는 바탕이 된다.
   최적 구성이 하나로 정해지지 않는 것은 설계 축마다 상충의 방향이 다르기 때문이다. 예를 들어 더 상세한 검색용 데이터는 검색 품질을 높이지만 저장량과 지연 시간을 늘리고, 메타데이터 조건을 강하게 적용하면 조건은 잘 지키지만 관련 영상을 놓칠 수 있다.
   끝으로, 이렇게 고른 구성이 검색 품질을 높이더라도 그 개선이 최종 VLM 답변으로 전파되는지는 별개의 문제다. 본 연구는 이 전파 조건을 증거 회수, VLM의 증거 인식, 과제 편향으로 나누어 답변 전파 실험에서 검증한다.

## 4.1. 비순환 작업 부하 구성과 순환성 진단

데이터 누수와 평가 순환성이 있으면 시스템이 영상 픽셀을 실제로 이해하지 못해도 성능 지표가 실제보다 높게 나올 수 있다[8,9]. 본 연구는 이 문제를 데이터베이스 검색 평가에 적용하여 기존 데이터셋을 그대로 재사용하지 않고 정답 정보의 유입을 차단한 비순환 평가 작업 부하를 설계한다. 이를 위해 메타데이터 조건은 센서 기록에서, 검색 문서는 영상 픽셀과 고정 프롬프트만을 입력받은 VLM이 생성한 설명문에서, 의미 검색 정답 집합은 사람 주석에서 각각 구성하여 세 원천의 생성 경로를 분리한다.
 본 연구는 정답 영상을 가려내는 데 사용한 라벨이나 주석을 메타데이터 조건 또는 검색 문서에 다시 사용하는 경우를 순환성으로 정의한다. 질의는 사용자가 찾고자 하는 내용을 포함하고, 정답은 그 내용을 실제로 담은 영상이므로 두 요소의 의미가 일치하는 것은 관련성을 평가하기 위한 필수 조건이며 그 자체를 누출로 보지 않는다. 순환성 검사는 메타데이터 조건과 검색 정답 집합의 출처가 분리되었는지, 메타데이터에 정답 필드가 포함되지 않았는지, 검색 문서에 정답 라벨이나 내부 필드명이 직접 노출되었는지를 자동으로 확인한다. 구체적으로 이 검사는 작업 부하 구축 시 자동 실행되는 여섯 가지 검증으로 구성된다. 모든 메타데이터 조건 키가 센서 유래 필드 5종에 속하는지, 모든 정답 정의가 사람 주석 유래 정의 5종에 속하는지, 두 필드 집합이 서로소인지, 메타데이터에 정답 정의 필드가 없는지, 전체 검색 문서에 정답 라벨과 내부 필드명 토큰이 노출되지 않았는지(정규식 검사, 허용치 0건), 그리고 정답 밀도가 희소성 기준을 만족하는지를 확인하며, 하나라도 실패하면 작업 부하 구축이 중단된다. 최종 작업 부하(문서 3,000개, 질의 85개)는 여섯 검사를 모두 통과했고 문서의 직접 라벨 노출은 0건이었다. 다만 이 자동 검사는 직접적인 필드·토큰 누출을 탐지하는 절차로서, 자연어의 우연한 의미 중첩이나 질의·정답 사이의 필수적인 의미 대응까지 통계적 독립으로 보장하지는 않는다.
비순환 작업 부하를 구축한 뒤에는 정답 정보를 의도적으로 다시 주입하여 순환성이 검색 성능을 얼마나 왜곡하는지 진단한다. 첫 번째 통제 주입(정답 조건 주입)은 정답 정보를 메타데이터 조건에 반영하여 정답 영상만 검색 후보로 남긴다. 두 번째 통제 주입(정답 라벨 재진술 주입)은 정답 정보의 의미를 문장 형태로 풀어 정답 영상과 대응하는 검색 문서에 추가한다. 두 실험은 정답 정보가 각각 메타데이터 조건과 검색 문서를 통해 유입될 때 발생하는 점수 상승을 측정한다.
첫 번째 통제 주입에서는 질의별 정답 영상만 통과시키는 조건을 적용한다. 하지만 정답 기반 조건은 검색 후보 수를 줄이는 동시에 정답 영상만 남기므로, 성능 상승이 후보 수 감소에서 비롯된 것인지 정답 정보의 사용에서 비롯된 것인지 그 결과만으로 구분하기 어렵다. 이를 구분하기 위해 각 질의의 정답 영상 수와 동일한 수의 영상을 전체 코퍼스에서 무작위로 선택하는 대조 조건을 구성한다. 본 연구에서는 이러한 무작위 선택을 1,000회 반복하여 동일한 선택도에서 나타나는 성능 분포를 산출하고, 이를 정답 기반 조건의 성능과 비교한다.
두 번째 통제 주입에서는 각 정답 영상의 캡션에 해당 영상이 정답인 이유를 직접 설명하는 문장을 추가한다. 이를 통해 원본 캡션을 사용한 결과와 정답을 재진술한 문장을 추가한 결과를 비교하여 정답을 암시하는 텍스트가 검색 문서에 포함될 때 점수가 얼마나 상승하는지 측정한다. 각 통제 주입에서는 질의, 코퍼스, 검색 정답 집합과 임베딩 모델을 동일하게 유지하고 주입 대상만 변경한다.

## 4.2. 데이터베이스 계층 설계 및 비교 축 정의

본 연구는 데이터베이스 계층을 다섯 설계 축으로 정의한다. ‘검색용 데이터‘는 mp4 포맷의 영상 클립의 시각 정보를 검색 가능한 형태로 변환하여 데이터베이스에 저장하는 형식이다. 클립 전체를 요약 서술한 텍스트 기반의 영상 설명문, 클립을 대표하는 단일 프레임 이미지 기반인 대표 이미지, 두 정보를 단일 벡터로 융합한 이미지·설명문 결합, 한 클립에서 여러 장의 주요 프레임을 추출해 각각 저장하는 다중 이미지, 그리고 설명문 텍스트와 다중 이미지 색인을 독립 구축하여 순위를 융합(Reciprocal Rank Fusion, RRF)[17]한 설명문·이미지 이중 색인으로 구성된다.
 ’검색 계획‘은 조건을 언제 어떻게 적용할지를 정하는 방식이다. 조건 없이 벡터 유사도만으로 찾는 벡터 단독 검색, 조건을 통과한 부분집합 안에서만 벡터를 검색하는 검색 전 조건 적용, 벡터 상위 후보를 먼저 찾은 뒤 조건에 맞지 않는 결과를 제거하는 검색 후 조건 적용, 그리고 사전 필터로 좁힌 부분집합에서 어휘와 벡터 순위를 역순위 융합하는 복합 계획인 혼합 검색으로 구성한다. 조건을 반드시 지켜야 하는 필수 제약으로 볼지(엄격한 정답) 검색을 돕는 관심 단서로 볼지(의미론적 정답)도 검색 계획 해석에 포함된다.
’검색 신호와 순위 융합’은 순위를 매기는 근거와 서로 다른 신호가 만든 순위를 하나로 합치는 방식을 함께 다루는 축이다. 필터를 통과한 클립을 식별자 순서대로 반환하여 조건과 의미 관련성의 결합도를 재는 기준선인 메타데이터 단독, 설명문 텍스트의 어휘 일치로 순위를 매기는 BM25 어휘[16], 임베딩 유사도로 순위를 매기는 벡터, 그리고 어휘와 벡터의 두 순위를 역순위 점수로 합산하는 BM25–벡터RRF으로 구분한다. 이에 더해 보조 신호로, 센서 조건 값과 영상 설명문에서 추출한 개체(고정 어휘집 8종, 문장 단위 부정 표현 배제)를 노드로 하고 사람 주석 경로의 간선을 배제한 경량 지식그래프를 구축하여, 메타데이터 조건 통과 부분집합 안에서 질의 관련 개체를 포함한 클립을 우선 배치하는 순위화를 평가한다. 개체별 리프트(Lift)는 해당 개체를 포함한 문서가 정답일 확률에서 전체 정답 비율을 뺀 값으로 정의한다.
‘물리 색인’은 벡터를 저장하고 탐색하는 자료구조다. 모든 벡터를 전수 비교하는 정확 검색 Flat, 그래프를 따라 이웃을 좁혀 가는 근사 색인 HNSW[18], 벡터를 여러 군집으로 나눈 뒤 일부 군집만 탐색하는 IVF-Flat, 그리고 IVF 구조에 벡터를 압축해 저장량을 줄인 IVF-PQ로 구성한다.
‘배포’는 색인을 어떤 범위로 구축해 운영할지를 정하는 방식이다. 전체 데이터를 하나로 색인하는 전역 색인, 자주 쓰는 조건별 부분집합만 따로 색인하는 조건별 부분 색인으로 구성한다.
혼합 검색은 메타데이터 조건 적용 시점(검색 계획)과 어휘–벡터 순위 융합(검색 신호)이 결합된 복합 계획이다. 따라서 본 연구는 이를 두 가지 관점으로 분리하여 통제 비교한다. 검색 계획 비교에서는 혼합 검색을 '검색 전 조건 적용 후 BM25 어휘 순위와 벡터 유사도 순위를 RRF(Reciprocal Rank Fusion)로 결합'하는 하나의 종단 실행 계획으로 평가한다. 반면 검색 신호 및 순위 융합 비교에서는 검색 전 조건 적용으로 추출된 동일 후보 집합 내에서 순수 벡터 순위와 BM25–벡터 RRF 융합 순위를 직접 비교하여 융합의 독립적 기여를 검증한다.

혼합 검색의 어휘 색인(BM25)은 자연어 텍스트 문서가 존재하는 영상 설명문 데이터에서만 구축할 수 있다. 이에 따라 영상 설명문(1종)은 네 가지 검색 계획(벡터 단독 검색, 검색 전 조건 적용, 검색 후 조건 적용, 혼합 검색)을 모두 지원하며($1 \times 4 = 4$개), 시각 벡터 중심인 나머지 네 가지 검색용 데이터(대표 이미지, 이미지·설명문 결합, 다중 이미지, 설명문·이미지 이중 색인)는 혼합 검색을 제외한 세 가지 검색 계획을 지원한다($4 \times 3 = 12$개). 따라서 유효한 검색용 데이터–검색 계획 조합은 총 $1 \times 4 + 4 \times 3 = 16$개다.

이 16개 유효 조합을 7개 물리 색인 설정(Flat 1개, HNSW $efSearch \in \{64, 256\}$ 2개, IVF-Flat $nprobe \in \{8, 32\}$ 2개, IVF-PQ $nprobe \in \{8, 32\}$ 2개)과 결합하여 총 $16 \times 7 = 112$개 호환 구성을 정의한다. 본 연구는 이 112개 전체 구성에 대해 85개 질의 및 2가지 정답 해석 기준(엄격한 정답·의미론적 정답)을 적용하여 총 19,040건($112 \times 85 \times 2$)의 검색 품질(nDCG@10, Recall@10)과 질의당 10회 반복 측정(총 95,200회)을 통한 검색 지연, 색인 용량을 다차원 파레토(Pareto) 관점에서 측정하고 평가한다.

# 5. 실험

   본 장은 실험에 사용한 여섯 연구 질문(RQ)을 정의하고, 이를 실제 데이터에 적용하여 검증한다. 평가 타당성부터 답변 전파까지의 의존 순서에 따라 RQ1을 먼저 검증한 뒤 RQ2–RQ5의 설계 축을 비교하고, 마지막으로 RQ6의 답변 효과를 확인한다.
   • 비순환 평가 타당성(RQ1). 같은 주석의 재사용은 검색 점수를 얼마나 왜곡하며, 본 연구의 세 원천 분리 프로토콜은 이를 진단하고 차단할 수 있는가?
   • 검색용 데이터 구성(RQ2). 영상 설명문, 대표·다중 이미지, 이미지·설명문 결합 벡터와 이중 색인은 검색 품질·지연 시간·저장 공간에서 어떤 절충을 만드는가?
   • 검색 계획(RQ3). 벡터 단독 검색과 검색 전·후 조건 적용, 혼합 검색은 조건이 필수 제약인지 관심 단서인지 및 조건–관련성 결합도에 따라 어떻게 달라지는가?
   • 검색 신호와 순위 융합(RQ4). 메타데이터, BM25 어휘, 벡터와 경량 지식그래프 신호는 순환 요소를 제거한 뒤에도 독립적인 검색 이득을 제공하며, 약한 신호의 순위 융합·재조합은 순위를 개선하는가?
   • 물리 색인과 배포(RQ5). 실측 조건의 선택도·군집성과 질의 빈도에 따라 Flat, HNSW/IVF 계열과 전역·부분 색인을 어떻게 선택해야 하는가?
   • 답변 전파(RQ6). 검색 결과의 차이가 최종 답변으로 전파되려면 증거 회수, VLM 인식과 과제 편향에서 어떤 조건을 충족해야 하는가?

AI Hub 교차로 데이터셋에서 센서 채널인 카메라 10은 시간·신호·교통량이 기록된 클립 32,880개, 시각 채널인 카메라 11과 22는 영상 클립 52,462개를 제공한다. 이 중 사람 주석과 연결된 52,210개에 대해 같은 교차로에서 촬영 시각 차이가 ±120초 이내인 가장 가까운 센서 클립을 연결하여 47,098개의 시각 클립을 확보했다. 이 47,098개에서 교차로×시간대 층으로 비례 층화하고 고정 시드 20260710으로 3,000개 클립을 표집하여 검색 코퍼스로 사용했다. 각 클립의 중간 이미지를 Qwen2.5-VL-7B-Instruct[24]에 입력하고, 교통량·차종·정차 및 주차 차량·보행자·도로·날씨 중 화면에 보이는 내용을 2–4문장으로 설명하도록 했다. 이 프롬프트는 평가 대상 범주를 명시한 과제-인지 프롬프트이다. 모델에는 픽셀과 프롬프트만 제공하고 센서 기록과 사람 주석은 제공하지 않았으며, 생성은 최대 110토큰의 탐욕적 디코딩을 사용했다. 이 Qwen2.5 설명문 코퍼스는 5.2.2절의 생성 모델 통제 비교에서 기준선이 되며, 비교 결과에 따라 RQ1의 통제 주입 실험과 RQ2의 데이터 구성 실험(표 4)은 동일 절차로 재생성한 Qwen3.5-9B[34] 설명문 코퍼스를, RQ3과 RQ4는 Qwen2.5 설명문 코퍼스를 사용한다.
질의는 시간대, 시각, 황색 신호, 보행 신호와 센서 교통 밀도의 메타데이터 조건 5종에 주차 차량, 개체 20개 이상, 버스 2대 이상, 정차 차량과 이륜차 2대 이상의 의미 조건 5종을 결합해 만들었다. 메타데이터 필드의 구체적인 조건값 22개와 의미 조건 5개의 조합에서 후보 110개를 만들고, 두 조건을 함께 만족하는 클립이 5개 이상인 질의 85개를 확정했다. 질의문은 사람이 자유롭게 어휘를 선택하지 않고 조건값과 사전에 고정한 의미 정의의 문구를 결합하는 템플릿으로 기계 생성했다. 따라서 자유 서술에서 생길 수 있는 직접 라벨 재진술은 줄였지만, 의미 정의와 정답 집합의 작성에는 사람 주석이 사용되며 양성 5개 미만의 조합을 제외했으므로 결론의 적용 범위는 이 지지 조건을 충족한 질의로 한정된다.

임베딩 모델은 각 실험이 비교하는 표현의 형태에 맞추어 선택한다. 검색용 데이터 형식 비교는 이미지와 설명문 텍스트를 하나의 벡터 공간에 두어야 하므로 Qwen3-VL-Embedding-2B[26]를 멀티모달 임베딩으로 사용한다. 설명문 생성 모델 비교와 검색 계획 및 신호 비교는 텍스트 설명문만 다루므로 텍스트 임베딩 BGE-M3[27]를 사용한다. 대규모 이미지 색인 실험은 이미지 벡터를 대규모로 색인하므로 이미지 임베딩 CLIP ViT-B/32[3]를 사용한다. 정리하면 RQ1의 통제 주입과 RQ2의 표 4는 Qwen3.5-9B 설명문·Qwen3-VL-Embedding-2B 조합을, RQ2의 생성 모델 비교와 RQ3·RQ4는 Qwen2.5 설명문·BGE-M3 조합을, RQ5는 CLIP 이미지 벡터를 사용한다. 따라서 RQ3의 벡터 단독 성능(0.170)과 RQ1·RQ2의 기준선(0.181)은 서로 다른 설명문·임베딩 조합에서 측정된 별개의 값이다. 개별 실험군 내에서는 동일한 임베딩 모델을 고정 적용하여 각 구성 간 검색 품질을 동일 척도인 nDCG@10으로 비교하며, 서로 다른 임베딩을 사용하는 실험군 간에는 상대적 차이를 중심으로 결과를 해석한다.
데이터베이스 계층 112개 구성의 통합 비교 실험에서 물리 색인은 Flat, HNSW, IVF-Flat, IVF-PQ를 사용한다. 여기서 HNSW는 노드당 최대 연결 수(M)=32, 색인 구축 시 탐색 범위(efConstruction)=200으로 구축한 뒤 검색 시 탐색 범위(efSearch)=64와 efSearch=256을 비교하며, IVF 계열은 총 군집 수(nlist)=64로 구축한 뒤, 검색 대상 군집 수(nprobe)=8과 nprobe=32를 비교하고, IVF-PQ는 분할 부분공간 수(m)=32, 부분공간당 6비트 코드북 양자화를 적용한다(대규모 색인 비교인 표 10에서는 m=32와 64를 함께 평가한다).
데이터베이스 적재 시 영상 설명문, 대표 이미지, 이미지·설명문 결합은 클립당 한 건을 저장하고, 다중 이미지는 클립당 최대 세 건을 저장하며, 설명문·이미지 이중 색인은 설명문 한 건과 최대 세 이미지를 각각 검색한 뒤 상수 60의 RRF로 결합하여 평가한다.
혼합 검색은 어휘 문서가 확보된 영상 설명문에 한해 적용하며, 검색 후 조건 적용은 벡터 검색 결과 상위 200개 후보군에서 조건에 부합하는 결과를 필터링한다. 이 코퍼스 환경에서 질의 85개, 엄격한 정답 6,809행, 의미론적 정답 24,872행을 고정하여 총 19,040건(112개 구성×질의 85개×정답 기준 2종)의 검색 품질을 측정하고, 지연 시간은 질의당 10회씩 총 95,200회 반복 측정하여 성능을 평가한다.

### 5.1.3. 평가 방법

 본 연구는 검색 품질 지표와 물리적 비용 지표를 함께 평가한다. 검색 품질은 정규화 할인 누적 이득(nDCG@10)과 검색 정답 집합 재현율(Recall@10)을 기준으로 평가한다. nDCG@10은 최종 답변 모델에 제공될 관련 증거가 상위 순위에 배치되는 정도를, Recall@10은 제한된 입력 문맥에 핵심 증거가 포함될 수 있는 검색 단계의 상한을 나타낸다. 근사 최근접 이웃의 정확도 평가는 Flat 전수 검색을 기준으로 한 상대적 Recall@10을 사용하여 색인·필터 실행 경로의 손실을 진단한다. 보고하는 시스템 비용은 float32 벡터 페이로드 또는 직렬화된 색인 크기, 색인 구축 시간, 준비 실행을 제외한 질의별 검색 지연(p50 및 p95)으로 제한한다. 원본 영상 저장, 설명문 사전 생성, 온라인 질의 임베딩, 네트워크 전송과 최종 모델 생성의 시간·비용은 포함하지 않으므로 본 연구의 비용 결과는 종단 비용이 아닌 데이터베이스 검색·색인 계층의 부분 비용이다. 절대 지연 시간은 계측 범위의 차이에 따른 잡음을 피하기 위해 동일 엔진과 환경 안에서만 상대 비교한다.
검색 계획의 효과가 질의와 필터 조건 간의 상관관계에 따라 어떻게 변화하는지 규명하기 위해, 질의 85개를 메타데이터 조건 통과 여부와 의미 관련성 간의 상관성을 나타내는 Cramér's V[28] 계수를 기준으로 층화 분석(Stratified Analysis)한다. 구체적으로 계수 0.3 미만의 저결합 질의 75개와 0.3 이상의 고결합 질의 10개로 분류한다. 이는 메타데이터 조건과 사용자 질의가 강하게 얽혀 있는 경우(고결합)와 결합이 약한 경우(저결합)에 따라 사전 필터링(검색 전 조건 적용)과 사후 필터링(검색 후 조건 적용) 중 어느 계획이 우수한지 조건부 가이드라인을 도출하기 위한 통제적 분석 방법이다. 한편 85개 질의는 메타데이터 조건 필드와 의미 조건의 조합인 25개 조건–의미 쌍(저결합 23쌍, 고결합 2쌍)에 군집되며, 결합도는 쌍 수준 속성이므로 결합도 밴드의 구간 추정은 쌍 군집 부트스트랩으로 보고한다.

유한한 실험 표본의 측정 불확실성을 정량화하기 위해 비모수 부트스트랩 95% 신뢰구간[29]을 보고한다. 변수 간 단조 관계에는 Spearman 순위상관분석[30], 구성 간 대응 비교에는 Wilcoxon 부호순위 검정[31]을 사용한다. 별도 표기가 없으면 양측 유의수준은 0.05이다. 다중 비교의 1종 오류를 통제하기 위해 보정 가족(family)을 결과 표의 동질적인 가설군 단위로 정의한다. 사전에 정의된 주요 비교쌍(예: 표 9의 엔진별 실측–무작위 대응 비교)에는 Holm 보정[32]을 적용하고, 사후 탐색적 비교(예: 표 4의 저장 방식 4개 비교)에는 Benjamini–Hochberg 보정[33]으로 허위발견율을 제어한다.
원 결과를 확인한 뒤 수행한 E0·S2–S4는 원 연구의 사전등록 실험이 아니라 후속 통제 분석이다. 다만 각 보강 분석은 신규 판정용 산출물을 만들기 전에 시드 20260723, 입력 해시, 주 추정량, 제외 규칙, 검정 가족과 성공·중단 기준을 문서로 동결했고, 실패한 게이트도 보존하였다. E0은 동일한 3,000개 프레임·Qwen2.5-VL snapshot·110토큰 상한·탐욕적 디코딩·BGE-M3·85개 질의·정답표·정확 검색을 고정하고 프롬프트만 과제-인지형에서 과제-중립형으로 변경했다. S2는 교차로를 결과와 무관한 해시로 5-fold 분리했고, S3는 predicate별 통과 수를 정확히 보존했으며, S4는 VLM 호출 전에 5%포인트의 과제 관련 검색 조작 게이트를 적용했다.

그림 2(b)는 모델과 데이터를 고정한 상태에서 순환성 요인만을 주입했을 때의 인과적 점수 상승 효과와 95% 신뢰구간을 보여준다. 이 주입 실험은 표 4의 영상 설명문 기준선과 동일한 앵커인 AI Hub 교차로 3,000개 클립의 Qwen3.5-9B 설명문 코퍼스와 Qwen3-VL-Embedding-2B 임베딩을 사용한다. 직접 정답 주입이 없는 기준 상태의 검색 품질(0.1810)과 비교했을 때, 메타데이터 조건에 정답 영상을 유출(정답 영상 필터)시키면 검색 성능이 1.0000으로 상승했다. 또한 검색 문서 텍스트에 정답 라벨을 재진술한 텍스트를 추가했을 때에도 0.8537로 품질이 상승했다. 이는 시스템 내부 알고리즘의 개선 없이도 단지 평가 데이터의 유출 경로가 존재한다는 사실만으로 품질이 정답 조건 주입 시 5.5배, 라벨 재진술 시 4.7배까지 부풀려질 수 있음을 입증한다. 단순히 후보군 수 감소로 인한 확률적 점수 상승 효과를 배제하기 위해 동일한 선택도를 가지는 무작위 대조군 조건(1,000회 반복)을 적용한 결과, 평균 nDCG@10은 직접 정답 주입이 없는 기준선(0.1810)보다 오히려 낮았다. 따라서 주입에 따른 점수 상승은 후보 수 감소가 아니라 정답 정보의 유입 자체에서 비롯된 것이다.
직접 정답 재사용 차단과 프롬프트 중립성을 구분하기 위한 후속 E0에서는 같은 3,000개 중간 프레임과 모델 snapshot·디코딩·질의·정답표·BGE-M3·정확 검색을 고정하고, 평가 범주를 열거한 프롬프트만 과제-중립 프롬프트로 교체했다. B2 의미론적 nDCG@10은 과제-인지 0.1700에서 과제-중립 0.0855로 감소했다(차이 −0.0845, 25개 질의 family 군집 부트스트랩 95% 신뢰구간 [−0.1672, −0.0044], 군집 부호반전 양측 p=0.0346, 질의별 승/동률/패 20/18/47). 과제-중립 캡션은 평균 생성 토큰이 73.9에서 93.9로 늘고 110토큰 이상 진단 건수도 11건에서 507건으로 증가했으며, bus·truck·two-wheeler의 문서 출현률은 각각 0.974→0.338, 0.870→0.154, 0.970→0.053으로 낮아졌다. 출력 길이와 범주 언급은 프롬프트 처치가 함께 바꾼 매개이므로 어느 하나에 하락을 단독 귀속하지 않는다. 이 결과에 따라 이하의 캡션 기반 절대 성능과 설계 비교는 과제-인지 프롬프트 조건부로 해석하며, 본 연구의 비순환성 주장은 직접 정답 정보 재사용의 차단으로 한정한다.

그림 3과 표 4는 검색용 데이터 구성이 검색 품질뿐 아니라 지연 시간과 저장량까지 변화시키며, 모든 시나리오를 지배하는 단일 최적 구성은 존재하지 않음을 보여준다.

먼저, 동일한 프레임·프롬프트·110토큰 상한과 BGE-M3 검색 파이프라인을 고정한 채 설명문 생성 모델만 교체한 결과, 후속 모델인 Qwen3.5-9B[34]는 Qwen2.5-VL-7B-Instruct 대비 의미론적 nDCG@10이 AI Hub 교차로 +0.102 [95% 신뢰구간 0.035, 0.171], MEVA +0.168 [0.144, 0.193], UCA/UCF-Crime +0.054 [0.015, 0.092] 높았다(질의별 대응 부트스트랩 10,000회). 이에 따라 데이터 구성 실험은 Qwen3.5-9B를 설명문 생성 모델로 고정하였다. 다만 Qwen3.5의 110토큰 상한 도달률은 AI Hub 2.57%, MEVA 15.84%, UCA 54.04%로 도메인별 차이가 컸다. 따라서 이 결과는 고정된 토큰 예산 아래의 검색 문서 비교이며, 생성 모델의 보편적 우위를 뜻하지 않는다.
표 4는 다섯 가지 검색용 데이터 구성의 품질–비용 절충 관계를 정리하여 보고한다. 본 연구는 AI Hub 교차로 3,000개 클립의 Qwen3.5-9B 설명문 코퍼스와 85개 질의 세트를 Qwen3-VL-Embedding-2B 멀티모달 벡터 공간에 매핑한다. 그리고 벡터 단독 검색과 Flat 정확 전수 검색으로 설정을 통제하여 데이터 구성만을 독립 변인으로 변화시키며 평가하였다. 두 실험 간 임베딩 모델의 차이로 인해, 본 결과의 절대 nDCG@10 수치는 앞선 VLM 성능 비교 결과와 직접 대비하지 않고 개별 실험 내에서만 상대적으로 해석한다. 또한, 검색 품질의 변화량을 정량화하기 위해 기준선인 영상 설명문 대비 각 구성의 nDCG@10 점수 차이를 효과량 ‘Δ’로 정의하였다.
기준선 대비 대표 이미지 구성은 저장량(24.6MB)이 동일한 조건에서 엄격한 정답(0.063)과 의미론적 정답(0.186) 모두 뚜렷한 품질 차이를 보이지 않았다(설명문 대비 Δ = +0.005 [−0.075, +0.079]). 이미지와 설명문을 동일 벡터 공간으로 융합한 이미지·설명문 결합 구성의 경우, 추가적인 저장량 증가 없이 의미론적 정답의 점 추정치를 0.181에서 0.218로 상승시켰으나, 효과량 Δ의 95% 신뢰구간(+0.037 [−0.005, +0.074])이 0을 포함하여 기준선 대비 확실한 성능 향상을 통계적으로 보장하지는 못하므로 추가적인 저장 자원 요구량 증가 없이 적용해 볼 수 있는 대안적 후보로 해석한다.
 가장 큰 품질 개선은 다중 벡터 기반의 정보 확장 구성에서 확인되었다. 다중 이미지 구성은 의미론적 정답 nDCG@10 기준 0.352의 가장 높은 점 추정치를 기록했다(Δ = +0.171 [+0.018, +0.316], 군집 부트스트랩 양측 p=0.028, 질의 수준 p<0.0001). 그러나 이 이득은 벡터 저장량이 24.6MB에서 68.4MB로 약 2.8배 늘고 p50 지연 시간이 1.15밀리초에서 3.65밀리초로 3배 이상 증가하는 물리적 비용을 동반한다. 또한, 저장 방식 4개 비교를 한 가족으로 한 Benjamini–Hochberg 보정 q값이 0.112로 확증 기준(0.05)을 넘지 못하므로, 이 우위는 유의한 확증 효과가 아니라 가장 유망한 점 추정 이득으로 해석한다. 텍스트와 다중 이미지 색인을 결합하여 상수 k=60의 RRF로 처리하는 이중 색인 구성 역시 의미론적 정답 0.293 (Δ = +0.112 [−0.004, +0.228])의 개선 효과를 보였으나, 저장량 93.0MB와 p50 지연 시간 4.96밀리초를 요구하여 다섯 구성 중 가장 높은 물리적 비용이 발생하였다.
그림 3은 4.2장에서 정의한 검색용 데이터 및 검색 계획의 16개 조합과 7개 물리 색인 설정의 곱으로 도출된 총 112개 호환 구성의 엄격한 및 의미론적 정답 품질과 p50 지연 시간의 관계 분포를 보여준다. 이는 품질 극대화와 물리적 비용 최소화를 동시에 충족하는 파레토(Pareto) 최적 경계를 함께 제시한다. 대표적인 사례로, 다중 이미지와 Flat 물리 색인을 고정한 상태에서도 메타데이터 조건의 처리 목적에 따라 평가가 극단적으로 엇갈렸다. 엄격한 정답 기준에서는 검색 전 조건 적용이 벡터 단독 검색보다 nDCG@10을 0.161만큼 향상시켰으나, 의미론적 정답 기준에서는 오히려 성능을 0.093만큼 하락시켰다. 결과적으로 RQ2 하에서 최적의 검색용 데이터를 선택하는 의사결정 기준은 단일한 최고 성능 수치로 고정될 수 없다. 따라서 서비스가 지향하는 정답 기준(엄격한 정답 및  의미론적 정답)을 먼저 확립하고, 인프라가 허용하는 지연 시간과 저장량 임계치 범위 내에서 파레토 후보군 중 최적의 구성을 조건부로 선택해야 한다.

### 5.2.3. 검색 계획 평가 (RQ3)

검색 계획(벡터 단독, 검색 전/후 조건 적용, 혼합 검색)의 영향력을 규명하기 위해, 실험은 Qwen2.5-VL-7B-Instruct 모델 기반의 3,000개 영상 설명문 코퍼스, BGE-M3 임베딩, 그리고 Flat 정확 전수 검색 구조와 85개의 질의 세트를 통제 변인으로 설정하여 평가를 진행하였다.

**&lt;표 5&gt; 질의 구성 방식 및 조건-의미 결합도에 따른 검색 전 조건 적용의 효과(Δ) - 의미론적 정답 기준**

결합도 밴드의 신뢰구간은 조건–의미 쌍(전체 25쌍) 군집 부트스트랩(5,000회)이다. 고결합 밴드는 2쌍뿐이어서 해당 구간은 두 쌍 평균의 범위와 일치하는 참고 값이며, 이 구간이 0을 배제하는 것을 유의성 근거로 삼지 않는다. 질의 수준에서는 Δ=+0.1335, 95% 신뢰구간 [+0.017, +0.249], 부트스트랩 p=0.024, Wilcoxon p=0.059(질의 10개 중 양수 7개)였다.
효과량 Δ는 검색 전 조건 적용과 벡터 단독 검색의 nDCG@10 점수 차이로 정의하며, 표 5와 표 6에 정답 기준 및 질의 특성별 효과량 상세 결과를 제시한다. 메타데이터 조건이 필수 제약으로 작동하는 엄격한 정답 기준에서는 검색 전 조건 적용(0.157)이 벡터 단독 검색(0.059)을 크게 앞서 유의한 성능 향상을 보였다(Δ = +0.0983, [95% 신뢰구간: +0.068, +0.133]). 그러나 이는 조건 충족이 정답에 강제되어 발생한 자명한 결과이다. 반면 메타데이터가 보조 관심 단서로 작동하는 의미론적 정답 기준에서는 조기 누락 위험으로 인해 벡터 단독 검색(0.170)이 가장 높은 성능을 보였고, 검색 전 조건 적용(0.154, Δ = −0.0158, [95% 신뢰구간: −0.047, +0.015]), 검색 후 조건 적용(0.150), 혼합 검색(0.133) 순으로 그 뒤를 이었다.
표 5는 이 효과가 질의 표본과 결합도에 따라 어떻게 달라지는지 정리한다. 질의 표본은 세 가지다. 최초 표본은 연구 초기에 수작업으로 선정한 조건–의미 조합에서 템플릿으로 생성한 32질의, 확장 표본은 전체 조건–의미 조합에 최소 양성 5개 규칙을 적용해 추가한 53질의, 통합 표본은 두 표본을 합친 85질의다. 관심 단서의 Δ는 최초 표본에서 −0.0745, 확장 표본에서 +0.0197, 통합 표본에서 −0.0158로 부호와 크기가 엇갈려, 필터 적용의 이득이 질의 표본 선택에 민감하게 반응함을 보여준다.
결합도는 메타데이터 조건 충족 여부와 장면 의미 관련성이 함께 나타나는 정도이다. 조건과 의미의 결합이 약한 저결합(V < 0.3) 조건에서는 검색 전 조건 적용이 성능 저하 경향을 보였으나(Δ = −0.0357), 조건과 의미가 연관된 고결합(V ≥ 0.3) 조건에서는 검색 전 조건 적용이 추가 이득 경향을 보였다(Δ = +0.1335). 다만 고결합 표본이 2쌍(질의 10개)에 불과하고 외부 데이터셋에서 재현되지 않았으므로(표 6), 이는 확증이 아닌 탐색적 근거로 제한한다.
동일 교차로 장면의 중복 상관을 차단한 후속 S2에서도 결론의 강도는 바뀌지 않았다. 63개 교차로를 5-fold로 완전히 분리하고 학습 fold에서 Cramér's V, held-out fold에서 B4−B2 의미론적 nDCG@10을 계산한 결과, 연속 V와 Δ의 Spearman ρ는 0.383이었다(p=0.059, 25개 family 부트스트랩 95% 신뢰구간 [−0.088, 0.727]). high fold 평균 Δ는 5/5 fold에서 양수였지만 유효 high family는 여전히 2개로 사전 승격 기준인 5개에 못 미쳤다. 따라서 “탐색적, 2쌍 한정” 판정을 유지한다.

표 6은 이러한 경향이 외부 데이터셋 UCA/UCF-Crime의 129질의 분석에서도 재현되는지를 점검한다. UCA 전체 135질의에서 정상 영상 조건 5개와 조건·정답이 겹친 퇴화 질의 1개를 제외해 129질의를 분석했다. UCA에서 필수 제약의 향상은 Δ=+0.1501 [쌍-군집 95% 신뢰구간 0.124, 0.179]였고, 관심 단서 적용 시의 의미 손실 경향은 Δ=−0.0485 [−0.130, 0.021]로 0을 포함했다. 강한 결합 조건의 추가 이득도 재현되지 않았다(Δ=−0.0558 [−0.154, 0.042]). UCA에는 독립 센서 채널이 없고 질의 수준 결합도 V≥0.3인 질의도 135개 중 3개뿐이어서 고결합 우위의 외부 대조는 탐색적 근거로 제한한다.

이 결과를 종합하면, 데이터베이스 계층을 설계할 때 메타데이터 조건을 하나의 획일적 필터로 처리해서는 안 된다. 시스템이 강제해야 하는 필수 제약에는 성능 저하를 막기 위해 검색 전 조건 적용을 채택하는 것이 유리하다. 그러나 의미 검색을 보강하려는 관심 단서에서는 무분별한 사전 필터링이 의미상 관련된 클립을 조기에 탈락시킨다. 따라서 관심 단서가 결합된 질의에서는 벡터 단독 검색을 기본으로 두거나, 사전 필터링이 의미론적 정답 기준에서 관련 영상을 누락시킬 가능성을 사후 검증한 뒤 도입해야 한다.

### 5.2.4. 검색 신호와 순위 융합 평가 (RQ4)

네 가지 검색 신호(메타데이터 단독, BM25 어휘 검색, 벡터 단독 검색, BM25-벡터 역순위 융합)의 통제 비교를 바탕으로, 직접 정답 정보 재사용을 차단한 평가 환경에서 어휘 신호와 그 재조합이 독립적인 검색 이득을 제공하는지 규명한다. 평가는 nDCG@10을 지표로 삼아 엄격한 정답과 의미론적 정답 두 기준으로 채점했다.
기준선인 메타데이터 단독은 엄격한 정답 0.218, 의미론적 정답 0.217을 기록했다. 이는 조건을 충족한 영상을 단순 ID 순으로 반환하므로, 검색기 자체의 순위화 능력보다 메타데이터 조건과 정답 의미 간의 물리적 결합도를 반영한다. 한편, BM25 어휘 검색은 엄격한 정답 0.017, 의미론적 정답 0.050에 그친 반면, 벡터 단독 검색은 각각 0.059와 0.170을 기록했다. 의미론적 정답 기준에서 두 검색 방식 간의 큰 성능 격차는 현재의 어휘 신호 변별력이 벡터 신호에 비해 매우 취약함을 의미한다.
순위 융합의 독립적인 기여 또한 검색 전 조건 적용 상태를 거친 부분집합을 바탕으로 검증했다. 검색 전 조건 적용 후보 안에서 벡터 순위만 사용한 의미론적 정답 점수는 0.154였다(조건 없는 벡터 단독 검색 0.170과 구분). 여기에 BM25 어휘 검색 순위를 RRF로 결합한 혼합 검색은 0.133으로 오히려 성능이 하락했다. 이는 입력 후보군과 검색 전 조건 적용 상태를 동일하게 통제하더라도 변별력이 약한 BM25 신호가 혼합되면서 검색 순위를 방해했음을 뜻한다. 따라서 순위 융합에 따른 개선 효과는 관찰되지 않았다.
지식그래프 재조합 역시 동일한 결과를 보였다. 4.2절에서 정의한 경량 지식그래프의 개체 리프트는 중앙값 0.002에 그쳤고, 문장 단위 부정 표현을 배제한 추출로도 중앙값 0.083까지 회복되는 데 머물렀다. 이 지식그래프로 필터 부분집합 내부를 순위화한 엄격한 정답 nDCG@10은 0.176으로 필터 내 무작위 순위(0.117)보다는 높았으나 메타데이터 단독(0.218)에 미치지 못했다. 결과적으로 RQ4는 BM25 어휘 검색, 순위 융합, 지식그래프 재조합 모두 직접 정답 정보 재사용을 차단한 평가에서 독립적인 성능 이득을 보이지 못했다고 결론 내린다. 따라서 실제 운영에서는 각 검색 신호의 품질을 사전에 검증해야 하며, 신뢰성이 확인되지 않은 약한 신호와의 무분별한 융합은 지양해야 한다.

표 7의 분석 결과에 따르면, 전역 HNSW 및 IVF 색인을 사용하는 모든 필터링 방식에서 실제 시공간 군집 조건에서 최대 0.627의 심각한 재현율 손실이 관찰되었다. 대조군의 변동 폭은 최대 0.047에 그친 반면 실제 환경에서 나타난 성능 격차는 컸다. 이는 검색 누락이 시공간적으로 조밀하게 군집된 데이터 분포와 일관되게 연관되어 있음을 보여준다. 단순 선택도만 일치시킨 무작위 조건은 실제 시공간 조건의 탐색 난이도를 반영하는 데 한계가 있어 실제 검색 손실을 크게 과소평가한다.
군집 기전을 분리한 후속 S3에서는 시내도로 24개와 교차로 22개 자연 predicate 각각에 대해 통과 벡터 수를 bit 수준으로 보존한 uniform label shuffle 100회와, 선택도 4수준·군집 집중도 5수준·anchor 10개의 합성 용량-반응 대조를 수행했다. 고정한 postfilter HNSW(M=32, efConstruction=200, efSearch=64)에서 자연 손실−shuffle 손실은 시내도로 +0.639 [predicate 부트스트랩 95% 신뢰구간 0.592, 0.686], 교차로 +0.305 [0.231, 0.381]였고, 집중도-손실 기울기는 각각 +0.521 [0.501, 0.541], +0.465 [0.442, 0.490]였다. IVF-Flat(nlist=1024, nprobe=8)에서도 자연−shuffle 차이는 +0.677 [0.609, 0.741], +0.234 [0.158, 0.316], 기울기는 +0.424 [0.405, 0.446], +0.349 [0.322, 0.378]로 네 조합 모두 사전 기준을 통과했다. 따라서 이 두 고정 CLIP 코퍼스와 시험한 postfilter HNSW·IVF-Flat 구성에서는 선택도를 고정한 embedding-space 군집 집중이 재현율 손실을 증가시켰다고 해석할 수 있다. 이 후속 통제 결과는 다른 encoder, ANN 구현, predicate 또는 운영 부하에 대한 보편 인과 법칙으로 확대하지 않는다.
이러한 재현율 결손을 복구하기 위한 실행 경로별 성능 개선과 연산 비용은 메타데이터 조건의 종류에 따라 큰 차이를 보였다. 표 8의 pgvector 환경 반복 스캔 평가 결과, 시간 조건은 지연 시간의 큰 상승 없이 재현율을 98% 이상 회복했다. 그러나 군집도가 높은 장소 조건은 재현율 복구 범위가 30~65% 수준에 머물렀고, 지연 시간은 최대 29.51밀리초로 급증하여 그래프 탐색 범위의 단순한 확대가 지닌 한계를 입증했다. 또한 표 9에 제시된 Milvus와 Weaviate[35] 환경 평가에서도 실측 조건의 재현율 손실이 재현되었다. Holm 보정 후 유의한 손실은 최대 +0.0098(Weaviate 시내도로)이었고, Milvus 시내도로에서는 더 큰 손실(+0.0140)이 관찰되었으나 표본이 6쌍이라 방향 일치로만 보고한다. 조건에 의해 필터링되는 비율이 약 92.3% 이상이거나 조건을 만족하는 벡터가 40,000개 미만일 때 시스템 실행 경로가 자동으로 전수 검색으로 전환되며, 이로 인해 재현율 결손은 0.0014 이하로 대폭 감축되었다. 한편 pgvector에서 조건별 부분 색인 6개를 실제 구축한 결과, 반복 스캔이 부분 복구에 그친 군집형 장소 조건을 포함한 선택도 0.011~0.774에서 동일 조건 정확 검색 대비 재현율 0.9812~0.9952, p50 지연 0.407~0.454밀리초를 기록했다(구축 0.38~39.15초, 크기 3.77~257.61MB). 이것이 초록과 서론의 부분 색인 결과 근거이며, 이 범위는 시내도로의 측정 조건에 한정한다. ### 5.2.6. 답변 효과 검증 실험 결과 (RQ6)

답변 효과 검증 실험에서는 검색된 증거의 품질이 언어 및 멀티모달 모델의 최종 답변 정확도에 미치는 영향을 평가했다. 설명문 증거 실험은 VRU-Accident의 4지선다 시각 질의응답 6,000문항에서 고정 시드 20260707과 6개 범주 균형으로 추출한 600문항을 사용한다(조건당 600문항, 무작위 정답률 25%). 고정된 생성 모델 2종(Qwen2.5-7B-Instruct[36], Llama-3-8B-Instruct[37])에 증거 조건만 변경하여(증거 없음, 무관 설명문, 벡터 검색 상위 3건, 메타데이터 사전 필터 결합 상위 3건, 정답 설명문) 탐욕적 디코딩으로 답하게 하고, 선택지 기호의 정확 일치로 채점하였다(판정 모델 불사용). 다각도 시점 실험은 다각도 CCTV 400사건 중 경계 상자 면적에 따른 시점 비대칭 층 250사건에서 사건과 질문을 고정하고, 우수·열세·양측 시점을 Qwen2.5-VL[24], Qwen2-VL[38], InternVL3-8B[39], Idefics2-8b[40]에 제공하여 대응 부트스트랩(5,000회)과 사전 설정한 5%포인트 등가 한계의 TOST로 비교하였다. 경계 상자 면적은 가시성의 대리 지표이며 실제 폐색 정답으로 해석하지 않는다.
설명문 증거 실험에서 Qwen2.5-7B의 정확도는 증거 없음 30.8% [95% 신뢰구간 27.2, 34.5], 무관 설명문 53.8% [49.8, 57.8], 벡터 검색 설명문 66.5% [62.7, 70.2], 대상 설명문 74.7% [71.2, 78.0]였다. 증거 없음에서 무관 설명문으로의 +23.0%포인트는 문맥·프롬프트 발판 효과까지 포함하므로 관련 증거의 효과로 해석하지 않는다. 관련성 차이를 직접 반영하는 무관 설명문 대비 벡터 검색의 +12.7%포인트는 95% 신뢰구간 [8.3, 17.0]과 McNemar 정확 검정 p<0.001로 지지되었고, 대상 설명문 대비 벡터 검색의 차이는 +8.2%포인트 [3.5, 12.7], p=0.0006이었다. 반면 메타데이터 사전 필터 결합과 벡터 검색의 차이는 +1.5%포인트, 95% 신뢰구간 [−2.0, 5.0], p=0.448로 유의하지 않았다. Llama-3-8B에서도 증거 없음 30.7%, 무관 설명문 52.8%, 벡터 검색 66.5%, 대상 설명문 69.0%의 순서는 같았지만, 대상 설명문과 벡터 검색의 +2.5%포인트 차이는 p=0.279로 확립되지 않았다.
다각도 시점 평가에서는 우수 시점과 열세 시점의 정확도 차이가 Qwen2.5-VL +5.6%포인트(p=0.0016), Qwen2-VL +15.2%포인트(p=0.0002), InternVL3-8B +8.4%포인트(p=0.0002)로 세 주 모델에서 같은 방향이었다. 우수 시점과 양측 시점은 이 세 모델에서 설정한 5%포인트 범위의 등가 판정을 충족하여, 시점을 추가하는 것보다 가시성이 높은 시점을 선택하는 편이 유효할 수 있음을 보였다. Idefics2-8b도 +4.4%포인트(p=0.0256)의 같은 방향이었지만 양측 시점 정확도 14.5%가 11개 범주의 무작위 수준 9.1%에 가까워 보조 결과로만 해석한다. 별도의 이진 객체 존재 질문 예비실험에서는 무관 프레임의 내용만으로 “예” 응답이 증가하는 과제 편향이 관찰되어, 이 형식은 색인→답변 효과의 확증 근거에서 제외하였다.
반면 근사 색인의 재현율 차이가 최종 답변까지 전파되는지의 검증은 두 단계 모두에서 확립되지 않았다. 소형 코퍼스(문서 1,000개, 색인 구성 27종)에서는 구성 간 증거 회수율 차이가 5% 이내로 좁아 색인 열화 조작 자체가 성립하지 않았다. 회수율 차이를 두 배 이상으로 벌린 대형 코퍼스(프레임 143,830개)에서는 VLM 호출 360건(조건당 180건) 중 증거 적중이 32건(정확 색인 22건, 강열화 색인 10건)에 그쳐 신뢰구간이 넓어 판정이 불가능했다(탐색적 결과).
이에 후속 S4는 이진 질문의 “예” 편향을 피하도록 bus와 bike 수를 0/1/2+로 묻는 3지선다 문항을 범주별 180개(클래스별 60개)로 고정하고, 같은 교차로×시간대의 다른 클래스 프레임을 우선 distractor로 정했다. 그러나 VLM 호출 전 모집단 2,739개에서 exact와 고정 strong-degradation 색인의 top-1 과제 라벨 일치율 차이는 bus +0.8%포인트(0.7605−0.7525, 교차로 부트스트랩 95% 신뢰구간 [−1.0, +2.7]), bike −1.1%포인트(0.7101−0.7211, [−3.1, +0.8])였다. 두 범주 모두 사전 설정한 5%포인트 검색 조작 게이트에 실패했으므로 대규모 VLM 호출을 수행하지 않았다. 이 중단은 부정 결과를 숨긴 것이 아니라, 답변 효과가 없는 것과 과제 관련 증거 처치가 없는 것을 혼동하지 않기 위한 판정이다.
결과를 종합하면 RQ6은 관련 설명문과 더 나은 시점의 제공이 통제된 조건에서 답변 정확도와 연관됨을 보이지만, 특정 검색 계획이나 ANN 재현율 개선이 최종 답변을 향상시킨다는 종단 효과는 확립하지 못했다. 이를 검증하려면 표본만 확대하기 전에, 별도의 개발 교차로에서 과제 관련 증거 일치율을 충분히 변화시키는 검색 처치를 선택하고 held-out 교차로에서 그 조작과 답변 효과를 순서대로 검증해야 한다.

## 5.3. 교훈 및 한계

본 평가 결과는 직접적인 정답 정보 재사용을 검사하는 비순환 평가의 필요성, 검색 품질·속도·공간 비용 간 상충 관계, 그리고 검색 개선이 VLM 답변으로 자동 전파되지 않는다는 교훈을 제공한다. 따라서 데이터베이스 계층은 실제 조건에서 품질과 비용의 절충안을 찾고, 검색 결과의 답변 전파를 별도로 검증해야 한다. 다만 자동 순환성 검사는 자연어 의미 중첩까지 배제하지 못하고, 생성 경로가 분리된 채널도 동일 장면·근접 시각에 연결되므로 통계적 독립을 보장하지 않는다. E0의 49.7% 상대 하락은 캡션 기반 결과가 과제-인지 프롬프트에 민감함을 보였고, 프롬프트 변경이 출력 길이와 범주 언급을 함께 바꾸었으므로 하락의 단일 매개는 식별하지 못했다. 표 3은 규모와 질의가 다른 진단 비교이며, 고결합 층은 교차로 차단 뒤에도 2쌍에 불과하다. S3의 군집 인과 해석은 두 고정 CLIP 코퍼스와 시험한 postfilter HNSW·IVF-Flat에 한정된다. 또한 S4는 과제 관련 검색 조작 게이트 실패로 VLM 호출 전에 중단되었고, 실시간 영상 유입·색인 갱신·동시 부하를 반영하지 못한 정적 환경, 원본 영상 저장·설명문 생성·최종 답변 생성 비용을 제외한 계측 범위 때문에 결과의 일반화가 제한된다. 본 연구는 기존 배포 데이터와 제공 주석만 사용하고 신규 인체 대상 자료를 수집하지 않았으며, 개인 식별·재식별을 평가 목표로 삼지 않았다. 실제 관제 배포에서의 개인정보 보호와 접근 통제는 본 연구 범위 밖의 별도 검토 사항이다.

# 6. 결론 및 향후 연구

   본 연구는 멀티모달 영상 RAG 파이프라인에서 데이터베이스 계층의 물리 설계를 비교하기 위해 직접 정답 정보의 재사용을 차단한 평가 작업 부하를 구축하였다. 주 평가 작업 부하에서 메타데이터 조건은 센서 기록, 검색 문서는 영상 픽셀 기반 VLM 설명문, 검색 정답 집합은 사람 주석에서 구성하고 직접 라벨 누출을 자동 검사하였다. 나아가 정답 기반 조건과 라벨 재진술 문장을 의도적으로 주입한 통제 실험을 통해 정답 정보 재사용이 검색 점수를 부풀리는 정도를 정량화하였다. 후속 E0은 이 차단만으로 프롬프트 비의존성이 성립하지 않음을 보였으므로 캡션 기반 결과를 과제-인지 프롬프트 조건부로 한정한다.
   이 작업 부하를 바탕으로 저장 방식, 필터 적용 방식, 검색 신호, 물리 색인과 배포 방식을 비교했다. 그 결과, 데이터베이스 계층의 검색 성능 최적화 구성은 정답 기준과 데이터 분포 및 자원 제약에 따라 달라졌다. 다중 이미지는 검색 품질의 가장 높은 점 추정치를 제공했지만 저장량과 지연 시간이 증가했다. 메타데이터 조건은 필수 제약과 관심 단서에서 서로 다른 효과를 보였다. 후속 선택도 보존 대조에서는 두 고정 CLIP 코퍼스와 postfilter HNSW·IVF-Flat에 한해 군집 집중이 재현율 손실을 증가시켰다. 관련 설명문과 가시성이 높은 카메라 시점은 VLM 답변 향상과 연결되었지만, 근사 색인의 검색 차이가 답변 품질로 전파되는 효과는 과제 관련 검색 처치가 충분하지 않아 확립되지 않았다.
   본 연구의 실험 결과는 데이터베이스 계층을 설계하는 순서를 제시한다. 먼저 평가 요소의 생성 경로를 검사하여 순환성을 차단하고, 메타데이터 조건을 필수 제약으로 볼지 관심 단서로 볼지에 따라 검색 정답 기준을 확정해야 한다. 이후 실측 조건에서 검색 품질·지연 시간·저장량·구축 비용을 함께 측정하여 파레토 구성을 선택하고, 선택한 검색 구성이 최종 답변에 미치는 효과를 증거 회수·VLM 인식·답변 변화의 단계로 나누어 검증해야 한다.
   향후 연구에서는 고결합 조건–의미 쌍을 확대하고, 범주 열거와 생성 길이를 요인별로 분리한 프롬프트 실험으로 캡션 의존 기전을 재검증할 예정이다. ANN→답변 실험은 별도 개발 교차로에서 과제 관련 증거 처치를 먼저 선택한 뒤 held-out 교차로에서 검증한다. 또한 실시간 영상 유입과 메타데이터 변경, 동시 질의를 포함하는 동적 작업 부하를 구축하고, 조건별 부분 색인의 생성·갱신·폐기를 자동화하는 관리 정책을 평가할 계획이다. 여러 VLM과 벡터 데이터베이스 엔진을 대상으로 검색부터 답변 생성까지의 종단 지연과 비용을 측정하여 본 연구에서 제시한 설계 교훈의 적용 범위도 확장하고자 한다.
