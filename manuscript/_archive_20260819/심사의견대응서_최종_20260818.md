심사위원 1의 리뷰 내용

서술적 심사평

- 본 연구는 대규모 영상 RAG 구축에 있어서 핵심적인 기술인 벡터 DB 기술(검색, 색인 등)의 한계점인 ‘평가 순환성'을 차단하는 비순환 평가 체계를 수립하고, 저장부터 배포까지 비용을 다차원적으로 고려하여 측정하고 분석하는 방법을 제안하고 있다. 이를 실제 시스템에서 확인하는 부분에서 큰 의미가 있는 논문이라고 할 수 있다.
  => 본 연구의 핵심 범위와 평가 순환성 차단의 의미를 이해해 주시고 평가해 주시어 감사드립니다. 개정 원고 전반에 걸쳐 평가 타당성 확보, 설계 대안 비교, 답변 전파 진단의 의존 순서를 일관되게 반영하였습니다.

세부 수정 의견

1. 다만 전체적으로 논문의 고유한 컨트리뷰션이 더 잘 드러나도록 방법론 부분을 명확히 할 필요가 있다.
   => 지적해 주신 내용에 따라 개정 원고에서는 기여를 세 단계로 재구성하였으며, 이 세 단계를 서론의 공헌과 4장의 방법론 구조에 동일하게 반영하였습니다.
2. 논문을 통해 제시하고자 하는 방법이 새로운 알고리즘인지, method 인지, 아키텍쳐인지
   수정보완이 필요하다.
   =>  본 연구는 평가 타당성 확보에서 설계 대안 비교와 답변 전파 진단으로 이어지는 단계적 평가 방법론임을 명확히 하였습니다. 이를 위해 비순환 평가 작업 부하의 구성·검사, 다섯 설계 축의 공통 비교, 세 단계 답변 전파 진단을 하나의 평가 흐름으로 연결하는 데 있음을 개정 원고에 반영하였습니다.
3. 또한, RQ6에서 기술이 되어있듯이 검색된 증거의 품질이 대형 언어 및 멀티모달 모델의 최종 답변에 얼마나 영향을 미쳤는지에 대해서는 유의한 결과를 확인하지 못했는데, 이에 대한 원인 분석이 5.3 절에 조금 더 추가된다면 논문의 퀄리티가 높아질 것 같다.
   => 개정 원고에서 RQ6의 원인 분석을 관련 클립 회수, 검색 문맥 인식, 과제 편향 통제의 세 단계로 수정하였습니다. 최종 답변 차이가 확립되지 않은 직접적인 원인을 답변 모델의 문맥 인식력 부족이 아니라 질의 관련 상위 검색 결과 차이의 미형성임을 개정 원고의 RQ6 관련 설명에 반영하였습니다.

심사위원 2의 리뷰 내용

서술적 심사평

- 본 논문은 멀티모달 영상 RAG 파이프라인에서 평가 데이터의 순환성을 차단하고, 검색용 데이터 구성과 검색 계획, 물리 색인에 따른 검색 품질과 비용을 실증적으로 분석한다. 연구의 독창성과 실험적 공헌도는 인정되나 몇 가지 수정사항이 필요하다.
  => 연구 범위를 명확히 요약해 주셔서 감사드립니다. 또한 연구의 독창성과 실험적 공헌을 긍정적으로 평가해 주셔서 감사드립니다. 개정 원고에서는 아래의 각 수정 제안 사항에 따라 수치와 계산 기준을 정정하고, 분석 단위와 재현 정보를 보강하였으며, 최종 PDF의 제목과 페이지 머리말을 점검하였습니다.

세부 수정 의견

1. 서론에서는 다중 이미지 구성의 의미론적 nDCG@10 이 0.181에서 0.418로 증가했다고
   기술하였으나, 5.2.2절과 표 4에서는 0.352로 제시되어 있어 수치를 일치시켜야 한다. 5.2.1절에서 검색 품질이 최대 4.7배 부풀려진다고 하였으나, 비순환 기준 0.181에서 정답 기반 조건 1.000으로 증가한 경우 약 5.5배에 해당한다. 4.7배의 계산 기준을 명확히 제시할 필요가 있다.
   => 정량적 수치에 대해 표기 오류라는 실수를 범하여 죄송합니다. 또한 이를 명확히 지도해주셔서 감사드립니다. 개정 원고에서 해당 수치 및 관련 지표들을 재확인하였습니다.
2. 5.2.3절에서는 고결합 질의를 10개로 분류하였으나 표 5의 분석 단위는 2개 쌍으로 제시되어 있다.
   => 해석에 어려움이 있는 부분을 지도해주셔서 감사드립니다. 개정 원고에는 조건–의미 쌍은 메타데이터 조건 종류와 의미 조건의 조합이며, 고결합 표본은 2개의 조건–의미 쌍에 포함된 10개 질의로 구성됨을 설명하였습니다.
3. 질의와 쌍의 관계 및 부트스트랩 표본 단위를 설명해야 하며, 외부 데이터셋에서 고결합 조건의 효과가 재현되지 않은 점을 고려하여 해당 결과의 일반화는 제한적으로 서술하는 것이 적절하다.
   => 개정 원고에 ’질의‘는 질의 단위 부트스트랩 재표집, ’쌍‘은 조건–의미 쌍 군집 단위 부트스트랩 재표집을 의미한다고 설명하였습니다. 또한 외부 데이터셋 비교는 고결합 효과의 재현을 주장하는 근거로 사용하지 않고, 메타데이터 조건을 필수 제약 또는 관심 단서로 해석할 때 나타나는 효과 방향을 비교하는 범위로 수정하였습니다.
4. 5.2.6절의 답변 효과 실험은 정확도 수치만 제시되어 있다. 사용한 답변 모델과 프롬프트, 조건별 표본 수, 채점 기준, 반복 횟수 및 불확실성 분석을 구체적으로 제시하고 결과를 표로 정리할 필요가 있다.
   => 개정 원고에는 답변 모델, 검색 문맥 조건, 문항 수, 디코딩, 채점 기준, 반복 횟수와 불확실성 분석 내용을 추가하였습니다. 또한 설명 보충을 위한 표 자료를 추가하였습니다.
5. 특히 무관한 설명문을 제공했을 때 정확도가 증거가 없는 경우보다 22%포인트 높게 나타난 원인도 설명되어야 한다.
   => 개정 원고에 검색 문맥 없음과 무관 설명문 조건의 차이를 선택지별 응답 분포와 문항 범주별로 분석한 내용을 반영하였습니다.
6. 표 2에서는 설명문 생성 모델을 Qwen2.5-VL-7B-Instruct 로 제시하였으나 5.2.2 절에서는 이후 실험에 Qwen3.5-9B 를 사용했다고 기술하고 있다. 각 데이터셋과 실험별로 사용된 설명문 생성 모델을 명확히 구분하여 제시해야 한다.
   => 각 RQ에서 사용하는 설명문 생성 모델과 임베딩 모델의 역할을 구분하여 서술하였습니다.
7. 본문의 페이지 머리말에 논문 제목과 다른 기존 제목이 반복적으로 남아 있으므로 전체적인 편집과 형식을 점검해야 한다.
   => 최종 PDF의 접수 양식, 본문 첫 페이지와 모든 페이지 머리말을 현재 논문 제목인 「종단형 멀티모달 RAG 파이프라인 성능 향상을 위한 비순환 평가 및 검색 품질-비용에 대한 실증 연구」로 통일하였습니다.
