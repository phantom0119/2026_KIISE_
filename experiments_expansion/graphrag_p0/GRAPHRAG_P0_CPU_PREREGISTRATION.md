## 0. 파일럿의 목적과 범위

본 파일럿은 개정된 연구 설계 — **동일한 정본 사실 표(canonical fact table)에서 그래프 표현과 텍스트 표현을 동기화하고, 원본/반사실 세계를 병렬 구축해, 그래프 구조 효과와 전체 시스템 효과를 분리 추정하는 요인 실험** — 의 실행 가능성을 확인한다. 파일럿은 다음만 판정한다:

1. 재료(자산·라이선스) 확보 가능성
2. 그래프·텍스트 동기화와 반사실 편집의 무결성(누설 0건) 달성 가능성
3. 증거 전달·비암기 표본·처치 강도의 확보 가능성 (일부 GPU 필요 → 보류 표기)
4. 본실험 표본 수 산정에 필요한 분산 성분(불일치율, 클러스터 ICC)

**파일럿이 판정하지 않는 것**: 연구 가설의 성립 여부(효과 크기·방향). 파일럿 표본은 본실험 표본에서 **전량 제외**한다.

## 1. 판정 단위와 원칙 (결과 확인 전 고정)

- **실험 단위 = 정본 사실 클러스터(canonical fact cluster)**: 하나의 사실(또는 편집된 엣지)에서 파생된 모든 질문·표현·모델 출력은 1개 클러스터로 취급하며 독립 표본으로 세지 않는다.
- 모든 원자료·코드·결과의 SHA-256을 `manifests/`에 기록한다.
- 첫 실행 오류·사후 수정은 숨기지 않고 본 문서 하단 "프로토콜 일탈 기록"에 추가한다(기준 완화는 불가, 기록만 가능).
- GPU 2장이 타 작업에 점유된 현 상태에서 기존 작업을 중단하거나 임의로 새 모델을 올리지 않는다. GPU 의존 게이트는 `PENDING_MODEL_PILOT`으로 보류한다.

## 2. 파일럿 게이트 (결과 확인 전 고정)

### F0. 자산 확보 [CPU]
- 최소 **2개 도메인**에서, 도메인당 **그래프/텍스트 동기화 가능한 정본 사실 ≥150개** 확보.
- 후보 소스(라이선스 검증 완료 2026-08-06): PrimeKG(Harvard Dataverse, CC0 1.0, ~3.2GB), STaRK(HF, 데이터 CC-BY-4.0/코드 MIT), HotpotQA(CC BY-SA 4.0, 지지 문장 보유), 기보유 FinQA·NQ 하니스.
- **주의(사전 명시)**: STaRK-Prime은 PrimeKG 파생이므로 두 소스를 독립 도메인 2개로 계산하지 않는다.
- 각 소스의 파일 해시·버전·라이선스를 `manifests/source_manifest.json`, `manifests/licenses.md`에 기록.
- **통과 기준**: 2개 도메인 × ≥150 사실쌍 + 라이선스 공개 가능성 확인. EA&B는 최초 제출 시 전체 재현 패키지 링크가 필수이므로(2026-08-06 검증) 공개 불가 소스는 채택하지 않는다.

### F1. 편집 무결성 [CPU]
- 반사실 편집이 그래프와 텍스트에 **100% 동기화**될 것.
- 원래 정답의 잔존·누설 **0건**: 별칭(alias), 역방향 관계, 대체 경로, 원문 청크, 프롬프트 템플릿까지 자동 감사(`scripts/audit_counterfactual_leakage.py`).
- **통과 기준**: 표본 전수 감사에서 동기화율 100%, 누설 0건. 1건이라도 미해결 누설이 남으면 실패.

### F2. 증거 전달 가능성 [CPU]
- oracle(정답 근거 직접 제공) arm: 정답 지지 사실 포함률 **100%** 확인.
- oracle 그래프/텍스트 arm이 **동일한 최소 사실 집합**을 갖는지 확인(사실 수 일치).
- retrieved arm: 텍스트/그래프 검색 각각의 gold-support recall을 측정·보고(통과 임계 없음 — 기록 의무만; 기보유 측정치: HotpotQA recall@16=1.000, FinQA=0.914).

### F3. 비암기 표본 [PENDING_MODEL_PILOT — GPU 필요]
- 반복 closed-book 프로브(질문 재표현 ≥3종 × 반복 ≥3회)로 안정적 비암기 사실이 **도메인·모델별 ≥100 사실 클러스터** 존재.
- 단일 오답으로 비암기를 판정하지 않는다. parametric knowledge probability(정답률 기반 연속값)를 기본 산출물로 한다.
- CPU 단계에서는 프로브 프롬프트 세트·판정 규칙만 고정한다.

### F4. 처치 강도 [PENDING_MODEL_PILOT — GPU 필요]
- 반사실 oracle 근거가 closed-book 대비 활성 세계(반사실 세계) 정답 추종률을 **≥20%p** 변화시킬 것.
- 그래프/텍스트 중 한쪽에서만 효과가 나타나면 프롬프트 형식·공정성 감사를 먼저 수행한 뒤 재측정한다.

### F5. 사람 채점 신뢰성 [부분 CPU/인력, judge 부분은 PENDING_MODEL_PILOT]
- 이중 독립 주석(≥2인) + 불일치 조정(adjudication), 주장(claim) 단위 분해.
- calibration set과 holdout set 분리. 시스템·도메인·원본/반사실 균형 층화 표집.
- LLM judge는 민감도·특이도와 시스템별 차등 오분류를 보고하고, 사전 기준(사람 대비 민감도·특이도 각 ≥0.85, 시스템 간 오분류율 차 ≤5%p) 미달 시 **주 분석에서 제외하고 사람 라벨을 주 결과로 사용**한다.
- CPU 단계에서는 주석 지침·표집 설계·기준만 고정한다.

### F6. 검정력 [CPU — 파일럿 데이터 필요 부분은 모델 파일럿 후 확정]
- 파일럿에서 짝지은 불일치율(paired discordance)과 개체/엣지 클러스터 ICC를 측정(`scripts/estimate_power.py`).
- 주 효과 SESOI(본실험 등록에서 확정하되, 실무적 의미 기준으로 5%p 안팎에서 파일럿 결과와 무관하게 정함)를 검출할 본실험 표본 수를 계산.
- **통과 기준**: 필요 표본 ≤ 확보 가능한 사실 클러스터 수. 초과 시 층·도메인·가설을 축소하며, 표본 부족 상태에서 "차이 없음"을 주장하지 않는다.

### F7. 공정성 [CPU]
- oracle 그래프/텍스트의 사실 수 일치, 토큰 예산 허용 오차(±10% 이내로 사전 고정) 준수.
- 동일 생성기·디코딩·지시문. 프롬프트 형식 차이가 결과를 만들지 않는지 확인하는 format-control arm 포함 여부를 모델 파일럿 전에 결정·기록.

## 4. 본실험과의 관계 (사전 명시)

- 파일럿 표본(사실 클러스터)은 본실험에서 전량 제외.
- SESOI는 파일럿 결과에 맞추지 않는다 — 실무적 의미로 먼저 정하고, 파일럿은 분산·불일치율·ICC와 표본 수 계산에만 쓴다.
- 본실험 주 비교 3개(사전 예고, 본실험 등록에서 확정): H1 = oracle 그래프 − oracle 텍스트(구조·표현 효과), H2 = retrieved GraphRAG − retrieved RAG(전체 시스템 효과), H3 = 세계(원본/반사실) × 표현 상호작용(기억 충돌). 질문 유형·커버리지·개체 인기도·생성 모델은 moderator, 나머지는 탐색 분석으로 분리. 주 가설 3개는 Holm 보정, 탐색은 BH-FDR, 차이 없음은 TOST/CI-포함 기준만 인정.
- 재검할 선행 주장(본실험 등록에서 정확 인용으로 고정, 후보): ① Han et al.의 "다중 홉 GraphRAG 우세·단일 홉 열세", ② 2606.22419의 "그래프 이득은 비학습 사실에 한정", ③ BRINK의 "불완전 지식 하 암기 의존". 역전·유지·동치 세 결과를 동등하게 보고한다.
