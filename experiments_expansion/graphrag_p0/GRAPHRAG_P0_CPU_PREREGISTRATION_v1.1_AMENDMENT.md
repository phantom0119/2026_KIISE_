## 수정 1. format-control arm 확정 (원본 F7의 보류 항목)

H1(oracle 그래프 − oracle 텍스트)은 그래프 구조, 삼중항 표현 형식, 어휘, 정보 배치 순서가 섞인 차이이므로, 다음 3-arm으로 분해한다:

- **A1**: 자연어 문장 근거 (동일 사실의 문장 표현)
- **A1F**: 동일 사실의 **평면 삼중항**(flat triples) 표현 — 구조·경로 순서 정보 제거, 무작위 순서
- **A2**: 연결성과 경로 순서를 명시한 **그래프 경로** 표현

분해된 비교식:
- **A1F − A1 = 표현 형식 효과** (표기법의 효과)
- **A2 − A1F = 구조적 조직화 효과** (연결성·순서의 효과)

이 통제가 실패하면(형식 간 사실 집합·토큰 일치 불가) 논문 주장 어휘를 "그래프 구조 효과(graph structure effect)"에서 "**구조화 증거 표현 효과(structured evidence representation effect)**"로 강등한다.

## 수정 2. F4 재측정 규칙 교체 (선택 편향 방지)

원본 F4의 "한쪽 arm만 효과 시 감사 후 재측정" 문구를 다음으로 교체한다:

- 프롬프트 수정은 **개발 세트(dev set)에서 1회만** 허용한다.
- 최종 처치 강도는 손대지 않은 **holdout에서 1회** 측정한다.
- 20%p 기준은 **전체 파이프라인의 조작(manipulation) 확인 기준**이며, 항목(사실) 제외 기준이 아니다.
- F4 실패의 판정은 "GraphRAG 효과 없음"이 아니라 "**해당 모델·설정에서 인과 비교 불가능**"이다.
- F4 결과를 이용해 유리한 사실만 본실험에 포함하는 행위를 금지한다.

## 수정 3. CPU 판정 라벨 통합 (원본 §3의 중복 해소)

원본의 `P0_CPU_PASS_TO_MODEL_PILOT`과 `P0_CPU_INCONCLUSIVE_MODEL_GATE_PENDING`은 동시 성립 가능하므로 폐기하고, CPU 단계 허용 판정을 다음 **3개로 확정**한다:

| 판정 | 조건 |
|---|---|
| `P0_CPU_PASS_MODEL_GATES_PENDING` | F0·F1·F2·F7 통과 + F6 검정력 **범위 시뮬레이션**상 실행 가능 영역 존재. 모델 게이트(F3·F4·F5-judge)는 GPU 확보 후 판정 |
| `P0_CPU_FAIL_DATA_OR_ALIGNMENT` | 동기화·누설 통제 불가 → 중단 |
| `P0_CPU_FAIL_POWER_ENVELOPE` | 어떤 합리적 가정 범위에서도 필요 표본이 확보 가능 사실 수 초과 → 중단 또는 범위 축소 |

## 수정 4. F6의 CPU 단계 범위 제한

실제 불일치율·ICC는 모델 출력 없이는 계산 불가하므로, CPU 단계의 F6은 **가정 범위 검정력 시뮬레이션**(discordance 0.05~0.40 × ICC 0~0.30 격자에서 필요 클러스터 수 산출)으로 제한한다. 실제 판정은 모델 파일럿 후 실측값으로 수행한다.

## 수정 6. 신규성 서술 추가 축소 (Co-E 반영)

**Co-E**(arXiv 2607.23278, 2026-07-25, 심사 전 — "동기화된 양방향 그래프-텍스트 작업 메모리", 원문 확인 2026-08-06)를 관련 연구에 추가한다. Co-E는 반사실 세계·증거량 통제·oracle/retrieved 요인 분해를 수행하지 않으므로 선점은 아니나, "그래프·텍스트를 함께/동기화해 사용하는 최초" 계열 표현은 사용 불가가 된다. 신규성 서술은 다음으로 고정한다:

> 그래프와 텍스트를 함께 사용하는 최초 연구가 아니라, **동일 정본 사실에서 그래프·텍스트와 원본·반사실 세계를 동기화하고, 검색 효과와 증거 표현 효과를 분리하는 통제 평가**.

또한 "관련 연구 원문 검증 전부 완료"라는 과거 표현은 철회한다 — 검증은 특정 날짜의 스냅샷이며(BRINK·KGHaluBench·Co-E가 순차 발견된 이력이 그 증거), 본실험 등록 전 ACL Anthology·DBLP 재스캔을 의무화한다.

## 수정 7. 의료 반사실의 안전 표기

의료 도메인의 반사실 사실은 **실험용 합성 정보**임을 모든 산출물에 명시한다: 별도 네임스페이스(`SYNTHETIC_CF__` 접두어), 데이터 카드(용도·경고 포함), 공개 패키지에 "실제 의료 지식 아님" 경고문. 공개 산출물이 실제 의료 지식으로 오인되지 않게 한다.
