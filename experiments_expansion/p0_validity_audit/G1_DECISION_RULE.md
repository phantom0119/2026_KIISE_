# G1 판정 규칙 (사전 등록) — 2026-08-05, arm 비교 결과 확인 전 고정

## 질문
난이도(HCBGen Post_Hardness) 분포를 맞춘 합성 조건 워크로드가 자연 조건 워크로드의 검색 난이도를 재현하는가? 재현하면 "자연 워크로드 축"은 불필요(G1 실패 → 주제 중단), 재현하지 못하면 G1 통과.

## 설계 (판정 전 고정)
- 코퍼스: 내부 A(132,521×512, 텍스트 질의 1,000), B(143,830×512, 이미지 질의 200, 자기 제외)
- 자연 arm: 균등(equality) predicate만 — A 24종, B 22종 (복합 predicate는 HCBGen 조건 문법상 제외, 문서화). predicate당 층화 시드 부표본으로 총 1,000쌍/코퍼스 (시드 20260805)
- 무작위 arm: W1에서 저장한 동일 선택도 대조 마스크(시드 20260805, replicate 0을 1차, 1·2는 강건성) × 동일 질의 — 짝지은 설계
- 매칭 arm: HCBGen match_pdf, 목표 분포 = 자연 arm 1,000쌍의 Post_Hardness(HCBGen 자체 추정기 v5.1), **질의 파일 = 자연 arm과 동일한 실제 질의**(질의 분포 고정 — 조건 부여만 격리; 프록시에 유리한 보수적 설계), Load 모드(실측 속성 정수 인코딩), num_bins 40, K=10
- 방법(naive 경로, G1 범위): postfilter_hnsw_K4x(ef=64), single_stage_ivf_np8, np32 — 원본 EXP03과 동일 구성. robust 경로는 G2 소관.
- GT: 전 arm 공통으로 본 스크립트의 정확 필터 top-10 (IP, B는 자기 제외). HCBGen 산출 GT는 교차 확인용.

## 1차 추정량
Δ_H(method, corpus) = mean per-pair Recall@10(자연) − mean per-pair Recall@10(매칭)

## 추론
- 클러스터 부트스트랩 95% CI, 5,000회 (자연: predicate 클러스터, 매칭: 조건 집합 클러스터)
- SESOI(최소 실질 효과): |Δ_H| ≥ 0.05 (Recall@10 절대값)

## 판정 (사전 고정)
- **G1 통과**: 두 코퍼스 중 하나 이상에서, naive 방법 중 하나 이상이 |Δ_H| ≥ 0.05이고 95% CI가 0을 배제; **또는** 방법 순위(3개 naive 방법의 평균 recall 순위)가 자연 vs 매칭에서 두 코퍼스 일관되게 뒤집힘
- **G1 실패**: 모든 방법·코퍼스에서 |Δ_H| < 0.05 또는 CI가 0 포함, 그리고 순위 뒤집힘 없음 → 자연 워크로드 축 중단(감사 문서 §11)
- **판정 불능 조건**: 매칭 arm의 달성 난이도 분포가 목표와 심하게 어긋나면(1-Wasserstein 거리가 자연 arm 난이도 표준편차의 0.5배 초과) 매칭 실패로 간주하고 판정 보류 — HCBGen 설정 재시도

## 사전 확인(사니티) — 판정과 독립
- Δ_R(자연 − 무작위)이 기존 EXP03 방향(자연이 크게 어려움)을 재현해야 함. 재현 안 되면 파이프라인 오류 조사 우선.

## 강건성(보고 의무, 판정 변경 불가)
- 난이도 빈(bin) 내 자연 vs 매칭 recall 비교
- 무작위 대조 replicate 1·2 교체
- B의 HCBGen 난이도 추정에 자기 항목 포함(1개 항목)의 영향은 무시 가능 수준으로 간주, 문서화
